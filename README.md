# 白曜的直播互动插件合集

抖音直播用的透明背景互动小游戏（OBS 浏览器源）。观众送礼、点赞、发弹幕来触发玩法，大部分插件同时支持 [白曜重工](https://github.com/mamba4live0918/baiyao-live-studio) 和菘蓝整蛊插件两种宿主，不开直播也能用按钮试玩。

> **English.** Transparent HTML overlay mini-games for Douyin live streams, loaded as OBS browser sources. Viewers' gifts, likes and chat drive the games through the Baiyao Live Studio or 菘蓝 plugin hosts. Each folder is one plugin; most have a `src/` + `tests/` + build script that inlines everything into a single HTML file.

## 构建

带 `build.cjs` / `build.mjs` 的插件：在插件文件夹里运行 `node build.cjs`（或 `node build.mjs`），把 `src/` 打包成单个 HTML；测试用 `node --test tests/`。没有 `src/` 的插件，HTML 文件本身就是成品。

## 仓库里没有的东西

- **打包成品和发布文件**：已有源码时，打包好的大 HTML、zip、PDF 说明书和演示视频都不进仓库。
- **大体积原图**：出摊啦 `源码/assets/raw/`（173 MB）、这个箱子怎么关不上 `源码/assets/raw/`（55 MB）、心动放映室的新版 CG 实验 `cg-lab/`（图片约 160 MB，整个文件夹没放）、抓萌宠通用版的 `开发/` 和 `素材/`。
- **QA 截图、临时文件、node_modules**。
- **授权不明的字体**：拼豆 `tools/fonts/`。其余随插件带的字体都是 SIL OFL（许可文件在各插件文件夹里）。
