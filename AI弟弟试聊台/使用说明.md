# AI 弟弟群聊试验室

这是一个本机群聊模拟器，不会登录抖音或接入真实粉丝群。需要本机安装 Node.js 18 或更高版本和网络连接，无须安装项目依赖。

1. 双击“启动试聊台.bat”，保持弹出的窗口打开。
2. 浏览器访问 http://127.0.0.1:8765/ 。
3. 在右侧填写 DeepSeek API Key，调整弟弟的名字和人设。密钥仅存在当前页面，刷新或关闭页面后需要重新填写，不要把密钥发到聊天消息里。
4. 选择或添加模拟群友，输入消息发送；也可以点击“让弟弟回复”。被叫到名字或 @AI 时会尝试回复，其他消息按互动频率决定是否回复。模型调用会产生服务商费用。
5. 在右侧选择群友，编辑记忆并保存；“整理聊天”会请模型提出记忆草稿，需你检查并保存。删除记忆不会自动清除聊天记录，清空聊天也不会删除记忆。
6. 关闭启动窗口即可停止本机服务。

聊天、人设和记忆保存在当前浏览器的本地存储中，清除浏览器数据会删除它们。模型回复会将人设、近期聊天及已保存的群友记忆发送给 DeepSeek；整理记忆时会发送所选群友的近期发言。试聊不要输入他人未同意提供的隐私或密钥。

如遇 API Key 错误、余额不足或网络连接失败，请检查 DeepSeek 账户和网络。浏览器刷新后密钥需要重填。如打开页面失败，请确认启动窗口仍在运行，且 8765 端口未被其他程序占用。
