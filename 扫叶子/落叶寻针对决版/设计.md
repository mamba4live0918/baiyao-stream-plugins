# 落叶寻针 v0.12 · 限时对决 2.5D 版 — 设计

2026-09-30。本文件是重构的设计定稿，开发计划依据本文拆分。旧版 v0.1–v0.11 的 HTML、源码和存档全部保留，不覆盖、不迁移。

## 1. 为什么要重构

v0.8–v0.11 的问题不在画面，而在结构：

- 为撑满「一局 1–2 小时」，叶堆堆到 3 万片，针上方至少 1200 层。观众送一次「加叶 300」，落到主播手边的只有十几二十层，主播几秒钟就捡回来了。
- 正俯视看几百层叶子，捡一片下面还是一片，进度和「差一点」都看不见，观众没法卡点捣乱。
- 偷偷搬针按设计不显示；加叶、回填只有一行小字提示。
- 四区、护区、封篮、三种冷却、4500/9000 次线索门槛、投票，观众看不懂。
- 观众没有「赢」的目标，捣乱只是拖时间。

重构目标：**捣乱看得见、有分量、能卡点、能赢。**

## 2. 已确认的决定

| # | 决定 |
|---|---|
| 1 | 限时对决：每局默认 5 分钟，超时算观众赢，屏幕记比分，整场连着打 |
| 2 | 不加动物角色，捣乱和帮忙全部用自然效果 |
| 3 | 观众赢一局就翻一张惩罚卡，并挂出本局捣乱王 |
| 4 | 主播接近针时，针附近一片区域冒反光（模糊区域，不暴露准确位置） |
| 5 | 针露出达到阈值才能按住拔出（阈值默认 60%，可调 10%–100%），拔针要按住一段时间（默认 1.5 秒，可调 0.5–5 秒）；叶子落回针上使露出比例跌回阈值以下，拔针进度清零 |
| 6 | 画面改为斜俯视 2.5D，镜头默认约 60°，可调 |
| 7 | 礼物、效果、档位和数值尽量都能自定义 |
| 8 | 以 OBS 浏览器源为首要运行环境，页面透明底（见第 9 节） |

## 3. 一局怎么玩

### 3.1 状态

`准备 → 进行 ⇄ 暂停 → 主播赢 / 观众赢`。结算画面停在「主播赢／观众赢」，主播点「下一局」或按空格才进入下一局的「准备」。

- **开局**：生成叶堆，针藏进中间层。开局时从镜头看针的露出为 0%，且针上方每个采样点的叶子层数都高于反光阈值，也就是开局既不露针，也不反光。
- **开始计时**：点「开始」、按空格，或直接捡第一片叶子。
- **空格**：未开始时开始；进行中暂停／继续；结算后开下一局。H 收起／展开操作面板，Esc 关闭设置。
- **暂停**：画面和计时一起冻结，叶堆盖一层薄雾（防止暂停偷看），新礼物排队。

### 3.2 主播操作

- **捡叶**：单击捡起视线上最前面的那一片，每片动作 0.3 秒，动作未完成时不能捡下一片。捡起的叶子沿弧线飞进木桶。
- **叶堆跟着动**（2026-10-01 按用户反馈「叶堆捡了没反应」修订，取代原「不做塌落」）：
  - **压实**：开局铺完叶先压实一遍，每片叶子都停在中心点下方最高那片之上。之后的塌落都是因为被捡才发生。
  - **下沉**：捡走一片后，中心靠它托着的叶子往下沉，压在上面的跟着连锁。
  - **滑坡**：表层叶子三成以上悬在挖出来的坑上空（比开局原始表面低 2 层以上），且挪 0.35 个叶宽能低 2 层以上，就顺坡滑进坑里。叶堆天然的陡坡不算，免得一碰就塌方。
  - **上限**：一次最多动 8 片。
  - **轻晃**：被捡处附近的表层叶子都轻晃一下。
  - **生效与画面**：逻辑位置立即生效，画面用约 0.3 秒补间。
  - **实测**：挖针所需拾取多 1～7%。挖出坑后，平均每捡 4～5 片有一片坑边叶子滑进去。
  - **范围**：扫一扫、顺风、一阵风、龙卷风拿走叶子后也会塌落，但不轻晃。
- **结霜时**：捡叶和拔针都被冻住，只能连点叶堆破冰（见 5.2）。

### 3.3 反光（接近信号）

- 针上方最薄处的叶子层数 ≤ 反光阈值（默认 8 层，模拟校准）时开始反光。
- 反光是白金色小星点，在一个圆形区域里随机冒出，闪一下即消失，同时有一声轻「叮」。区域半径默认 120（按 1440 宽画面计）。圆心相对针有随机偏移（不超过半径的 60%），针本身不被高亮。
- 层数越少闪得越勤：阈值处约 2.5 秒一次，只剩 1 层时约 0.6 秒一次。
- 叶子被盖回、层数回到阈值以上时，反光停止。

### 3.4 露针与拔针

- **露出比例**：沿针身取密集采样点，从镜头沿视线检查每个点是否被叶片（透明度 ≥ 0.5 的像素）挡住，未被挡住的比例即露出比例。按镜头实际看到的算，所以又窄又深的坑，前壁会挡住坑底。
- **露出 > 0%**：针可见，旁边显示「露出 35%」。此时点在针上只提示「还拔不动」。
- **露出 ≥ 拔针阈值**（默认 60%，设置里可调 10%–100%）：针发亮，提示「按住拔出」。
- **拔针**：在针的可见部分按住，默认 1.5 秒（可调 0.5–5 秒），针一点点被抽出，旁边有一圈进度。松手、露出比例跌回阈值以下、针被龙卷风卷走，任何一种情况都会让进度清零。
- **压哨**：计时归零时如果正在拔针，允许继续拔完；期间捣乱照样能打断。

### 3.5 胜负与结算

- **主播赢**：拔针完成。针从叶子里拔出、放大闪光、撒花，显示「找到了！用时 03:41」和本局护驾王；比分主播 +1。
- **观众赢**：计时归零且没有处于压哨拔针。叶堆区域稍微压暗（不给整页加底色），聚光灯打在针的位置，挡住针的叶子变透明，显示「就在这！还差 N 片」（N = 此刻从镜头看挡住针采样点的不同叶片数）；接着翻惩罚卡，下面挂捣乱王；比分观众 +1。
- **比分**：「主播 X : Y 观众」整场累计，设置里可以清零。

### 3.6 礼物排队

在准备、暂停、主播赢、观众赢期间收到的礼物和点赞奖励不作废，进入排队，在下一局开始计时的那一刻按到达顺序生效。队列最多 200 条，超出时把同一规则的条目合并（份数相加），不丢弃。

### 3.7 保存与刷新

- 保存内容：比分、局数、阶段、剩余时间、叶堆（每片的位置、高度、朝向、种类）、针、木桶里的叶子及其原位置、排队中的效果、正在持续的状态（剩余结霜层数、快手剩余时间）、本局贡献记录、惩罚牌堆位置、点赞累计与零头、已处理事件 ID。
- 时机：约每 10 秒一次，另外在每局结束、比分变化和页面关闭时各保存一次。
- 保存时，正在播放的效果直接结算到结束状态；刷新后恢复为暂停，已生效的效果不重播、不重复生效。拔针进度不保存。
- 浏览器无法保存时提示「仅本页生效」；读不了的旧记录不被新局静默覆盖。
- 设置和局面快照都存 `localStorage`（白曜只同步 `localStorage`），存储名前缀 `autumn-needle-duel-v12`。快照用紧凑编码，1600 片叶子约 70 KB。
- **多个页面同时打开**：白曜的设置窗口、画布和 OBS 源会各开一个页面，共用同一份存档。规则如下：
  - 只有在本页开过局或捡过叶子的页面才写局面快照；只打开设置的页面只写设置。
  - 快照带递增版本号和时间，读取时取最新的一份。
  - 设置变化通过 `storage` 事件即时生效，收不到事件时刷新后生效。
  - 「比分清零」「局数重置」「重新洗牌」会改动局面数据。这几项以带编号的指令写入，由正在玩的页面执行一次；当时没有正在玩的页面，就由下一个开局的页面执行。
  - 使用说明里写明：同一时间只放一个落叶寻针来源。

## 4. 叶堆与 2.5D

- **坐标**：地面为 (x, y)，高度为 z，单位与 1440×810 画面的像素相当。叶堆底面是一个椭圆，位于画面中下部，上方留给主播画面。
- **镜头**：透视镜头对准叶堆中心，仰角默认 60°，设置里可调 45°–75°；视场角较小（约 30°），远近大小差不明显。整幅画面按窗口等比适配，多余区域透明（沿用 v0.11 的 layout）。
- **叶片**：沿用图集里的六种可爱叶片，贴在 3D 薄片上，带随机朝向，保持水平不倾斜（开发中修订：倾斜几度就会让相邻两层在画面上交错，点到的和看到的不一致；明暗改靠深度来体现）。高度由堆叠决定：新叶的高度 = 已经盖住它中心点的叶子数加 1，再乘以每层厚度（叶子是软的，贴着下层）。这样堆高和该处的层数成正比。前后顺序统一按「高度，其次后放的在上」判定，点选、露出比例和绘制都用这同一个顺序。高度网格（格子 8 单位）记录每处最上面那片叶子的高度，用于明暗和反光位置。每层的视觉厚度在小样阶段调，要求十几层的叶堆看起来是一座明显的小丘。
- **叶量**：默认约 1200 片，叶堆平均十几层，中间厚、边缘薄，最终数量由模拟定。设三档叶量：轻松／标准／困难。
- **点选**：从镜头经鼠标位置发出射线，按空间网格找候选叶片，取第一片在该点透明度 ≥ 0.5 的叶片。
- **深度看得见**：叶片按「比开局时的原始表面低多少」变暗（开发中修订：按周围最高处比较会把自然坡面也压暗），没挖过的表面保持明亮，坑越深越暗；空中的叶片在地面投下柔和的影子。
- **针**：用代码画的银色细针（带高光和针眼），长约 150，接近水平地夹在中深层。选位要求：针下方也有叶子、离叶堆边缘足够远、不在无堆积区内、开局露出 0%。
- **木桶**：用图集里的笑脸木桶（本来就是斜视角），立在叶堆右侧。
- **叶子可以溢出**（用户确认）：开局叶堆铺在椭圆里，之后效果带来的叶子可以落在画面任何位置，不强行限制范围。空间哈希和高度网格要覆盖整个可见画面（包括各个仰角下画面顶端对应的远处地面），落在画面上的叶子都能点到；落到画面外的算溢出，不再处理。
- **护脸圈**（硬规则，用户确认）：把圈当成一块透明的实体。开启后，任何叶子都进不去：开局叶堆、各种效果带来的叶子、溢出的叶子都不会落在圈里；空中飞的叶子（落叶雨、龙卷风、篮子炸开、飞进木桶的叶子）碰到圈会被弹开或沿边滑开，不会穿过去。圈在屏幕上，判断时按叶片在画面上的实际投影（含高度）计算：落地的叶子挡到圈就沿地面推到圈外，飞行中的叶子挡到圈就沿垂直于视线的方向推出圈外并改变速度方向。调整镜头仰角或拖动、缩放圈时，重新检查所有叶子。开关沿用 v0.11：默认关，保留拖动、缩放和保存。
- **性能**：WebGL2 实例化绘制叶片，高度网格和空间网格只做局部更新。
- **降级渲染**：WebGL2 创建失败或上下文丢失且无法恢复时，自动切换到 Canvas 2D 简化渲染。简化渲染画的是同一个 3D 叶堆：按远近顺序绘制，每片叶子用仿射变换近似透视，深度明暗使用预先调暗的叶片贴图，效果粒子减量。点选、露出比例和反光都由 `pile.js` 计算，与渲染方式无关，所以两种渲染下玩法完全一样。降级时角落提示「简化显示」。

## 5. 观众能做什么

### 5.1 通用规则

- 捣乱都冲着**主播正在挖的地方**：目标点取最近 20 秒内最后 8 次拾取位置的重心；还没捡过时，取叶堆上随机一点。
- **「坑」**的定义：当前堆高比开局低 2 层以上的格子。
- 不同的效果一收到就生效，可以同时出现；同一个场面型效果有多份时依次上场（见下表）。
- 每个效果都分小、中、大三档，参数独立；档位越大，画面越大。
- **送多个**只乘份数或次数，不会自动升档：

| 类型 | 效果 | 多份时 |
|---|---|---|
| 数量型 | 飘落叶、扫一扫、篮子炸了、顺风 | 份数相加，作为一次更大的效果生效 |
| 场面型 | 一阵风、落叶雨、龙卷风、阳光 | 每份单独上场，同一效果一个接一个（前一个结束后约 0.5 秒接下一个） |
| 叠加型 | 结霜（叠层数）、快手（叠时长）、加时（叠秒数） | 累加 |

### 5.2 效果与三档默认值（均可改，模拟后微调）

**捣乱**

| 效果 | 画面 | 参数 | 小 | 中 | 大 |
|---|---|---|---|---|---|
| 🍂 飘落叶 | 叶子从上方飘到目标点附近落定 | 每份新增片数 | 5 | 15 | 40 |
| 🌬 一阵风 | 风线横扫，高处的叶子贴地滑进目标附近的坑 | 移进坑里的片数（叶子总数不变） | 25 | 40 | 80 |
| 🧊 结霜 | 叶堆覆半透明冰面，每点一下多一道裂纹，点够碎开 | 每层要点的次数 | 10 | 20 | 35 |
| 🍁 落叶雨 | 整屏落叶，七成落进坑里 | 新增片数 | 60 | 120 | 250 |
| 🧺 篮子炸了 | 木桶鼓起、抖动、砰地弹开，叶子沿抛物线飞回原位 | 退回最近捡的片数 | 30 | 60 | 120 |
| 🌪 龙卷风 | 漏斗形旋转叶柱穿过目标区域，吸起叶子，最后撒进各处坑里 | 持续秒数 | 4 | 6 | 9 |
| | | 半径 | 70 | 100 | 140 |
| | | 最多卷起片数 | 60 | 120 | 220 |
| | | 能卷走多深的针 | 不卷 | 上方 ≤ 10 层 | 上方 ≤ 15 层 |

- **篮子炸了**：木桶里不够时有多少退多少；退回的叶子落在各自原位此刻的表面上。
- **结霜**：停手 1.5 秒后，当前层进度每 0.4 秒回落 1 下。多层时只显示当前这一层的进度，旁边标「×3」。冻住期间计时照走，礼物照常生效。连点的是鼠标，不需要键盘焦点。
- **龙卷风卷针**：路径经过针（针在半径内）、且针上方层数不超过该档上限时，针闪着光被甩出，沿抛物线落到至少 250 外的随机位置，再被随后落下的叶子埋到反光阈值以上 2 层。拔针进度清零，反光停止。

**帮忙**

| 效果 | 画面 | 参数 | 小 | 中 | 大 |
|---|---|---|---|---|---|
| 🧹 扫一扫 | 目标点附近最上面的叶子一片片飞进木桶 | 每份片数 | 3 | 8 | 20 |
| 🍃 顺风 | 暖色风线，目标点附近一片叶子被吹起飞走 | 吹走片数 | 25 | 40 | 100 |
| ✋ 快手 | 光标周围金色光环，带环形倒计时 | 持续秒数 | 5 | 10 | 20 |
| | | 每点一下连捡层数 | 2 | 3 | 4 |
| ☀️ 阳光 | 暖黄光带斜扫过去，留下包含针的柔光圈，慢慢变淡 | 光圈面积占叶堆 | 1/3 | 1/4 | 1/8 |
| | | 亮几秒 | 6 | 8 | 10 |
| ⏱ 加时 | 计时数字弹一下「+30」 | 秒数 | 15 | 30 | 60 |

- **「最上面的叶子」**：上方没有其他叶片压着的叶子，按高度从高到低取。
- **快手**：每次点击先捡中那一片，再沿同一视线继续捡后面的，直到达到层数。一次动作捡起多片，动作时长仍是 0.3 秒。
- **阳光**：光圈一定包含针，圆心随机偏移。
- **加时上限**：剩余时间最多 15 分钟。

### 5.3 礼物规则

- 每条规则 = 礼物名 + 效果 + 档位 + 每个礼物算几份。可以新增、删除，每条都有测试按钮。
- 礼物名宽松匹配（忽略首尾空格、大小写、全角半角和符号）。一个礼物名只能绑一条规则，重复时设置页标红并拒绝保存。
- 礼物个数 × 每个礼物的份数 = 本次份数。

| 摸摸头 | 快手 | 中 | 1 |
| 浪漫营地 | 顺风 | 中 | 5 |

结霜、加时默认不绑礼物，由主播指定。全新配置首次打开时自动写入一次上表，之后以主播的修改为准。

### 5.4 点赞

- 默认开启：本场点赞每累计 1000 个，触发一次「飘落叶·小 ×2」（10 片），算捣乱，不计入捣乱王分数。
- 可以改累计步长、效果、档位、份数，也可以关闭。累计总数和零头会保存；「比分清零」时点赞累计一并清零。

### 5.5 谁干的：横幅、说明牌、捣乱王

- **横幅**：从比分牌下方滑出，格式为「头像 @昵称 召来了 🌪 龙卷风·中 ×N」。宿主提供头像网址且加载成功就显示头像，否则用昵称首字做圆章；没有昵称时显示「观众」。每条停留 2 秒（大档 3 秒），依次轮播；同一人 3 秒内连送同一效果，合并为「×N」。
- **说明牌**：画面左下，按当前礼物规则自动生成「礼物名 → 图标 效果·档位」，捣乱暖色、帮忙冷色分两组。可以收起、拖动，位置会保存；设置里可以整块隐藏。
- **捣乱王 / 护驾王**：本局按「档位分（小 1、中 5、大 20）× 份数」累计，点赞不计，同分时先到者优先。比分牌左侧实时挂护驾王，右侧挂捣乱王，结算时再显示一次。

### 5.6 惩罚卡

- 设置里一行写一条惩罚。默认几条示例：学三声猫叫、清唱一句、做 10 个深蹲、用夹子音念一句观众弹幕、对镜头比心 5 秒。
- 洗牌抽取，一轮抽完之前不重复，抽到哪里会保存。清单为空时，只显示捣乱王，不翻卡。
- 卡片用 CSS 3D 翻面。

## 6. 画面与界面

- **沿用**：v0.11 的奶油色 HUD、可可色文字和衬线标题风格。
- **透明**：HTML、body 和画布全部透明，只显示叶堆、木桶、HUD 和面板，细则见第 9 节。
- **比分牌**（顶部正中）：「主播 X : Y 观众」、「第 N 局」、大字倒计时。最后 30 秒变红并跳动，最后 10 秒有读秒音。
- **针旁标签**：「露出 N%」／「按住拔出」／拔针进度环。
- **操作面板**：默认收起，按 H 或点右下角按钮打开。内含开始、暂停、下一局、模拟礼物（每个效果每档一个按钮，加模拟点赞），以及设置入口。双击空白处也可以打开设置。
- **动画**：装饰动画（轻微抖屏、叶子待机轻晃）默认开启，可选「跟随系统」或「关闭」；选「开启」时不受系统「减少动画」影响。效果和结算动画本身是玩法信息，始终播放。
- **声音**：WebAudio 合成。包括捡叶、反光「叮」、各效果、读秒、胜负音效；有总开关和音量。
- **试玩页**：`试玩.html` 在插件外层提供背景切换（暖雾紫、浅色、棋盘、绿幕），只用于检查透明效果；插件本体始终透明。

## 8. 接入

- 菘蓝 SDK 优先：`onGift` 处理礼物，`onLike` 处理点赞（点赞数据需要宿主提供）；没有 SDK 时手动连接 `ws://localhost:10030`，断线 3 秒重连。
- 事件 ID 去重（60 秒窗口，最多记 500 条）；已处理的 ID 随存档保存，刷新后同一事件不会再次生效。
- 页面公开 `window.AutumnNeedle`：`receiveGift(message)`、`receiveLike(message)`、`getState()`，方便本地联调。
- 头像只在宿主提供网址时尝试加载；白曜等禁止网络的宿主会自动退回昵称圆章。
- OBS「交互」窗口按键：沿用其他插件的 `obs-key-shim.js`。

## 9. OBS 浏览器源与透明底

目标环境是本机 OBS Studio 32.2.2（Steam 版，内置 Chromium 127）的浏览器源。同一个 HTML 也要能在普通浏览器、菘蓝和白曜里使用。

**透明底**
- HTML、body 和画布在任何状态下都透明，只显示叶堆、木桶、HUD、横幅、说明牌和已打开的面板。
- 不做整页遮罩：结算压暗、暂停薄雾只作用在叶堆区域；打开设置时不给整个画面加模糊或暗色。
- WebGL 画布使用带 alpha 的上下文，清屏为全透明，着色器输出预乘 alpha 的颜色。这样叶片边缘、阴影、反光和霜面在 OBS 里合成时不会出现黑边或白边。Canvas 2D 简化渲染同样透明。
- 试玩页的背景只在插件外层，插件本体始终透明。

**在 OBS 里操作**
- 主播在浏览器源的「交互」窗口里玩：单击捡叶、按住拔针、连点破冰都用鼠标完成，不依赖鼠标悬停。
- 键盘只用于空格、H、Esc 等快捷键。页面最前面加 `obs-key-shim.js`，补齐 OBS 转发按键时缺少的按键编码和长按标记。
- 不使用浏览器原生弹层：下拉框改为页面内选项列表（沿用抓萌宠的做法），确认框改为页面内确认框，不使用 alert、prompt 或原生取色器。
- 动画和计时都按真实时间计算，OBS 以 30 帧或 60 帧渲染都不影响计时和效果时长。
- 音效用 WebAudio。OBS 里可以直接播放，普通浏览器在第一次点击后开始发声；可以勾选 OBS 的「通过 OBS 控制音频」。
- 如果勾了「不可见时关闭源」或「场景激活时刷新浏览器」，页面会重新加载，局面按 3.7 节恢复为暂停。
- 代码和样式只使用 Chromium 127 已支持的特性，因为内置浏览器的内核更新，本地能跑不代表 OBS 里能跑。
- 白曜在 OBS 页面里会先注入 SDK；设置窗口打开期间，白曜会暂存直播事件，关闭设置后按原顺序补发。事件去重只拦截重复的事件 ID，不会丢掉补发的事件。

**推荐设置（写进使用说明）**
- 浏览器源宽高设为 1920×1080 或 1280×720（16:9，与 1440×810 画面同比例）。可以勾「本地文件」直接选择 HTML；换了文件路径，存档会跟着换。
- OBS「设置 → 高级 → 浏览器源硬件加速」保持开启。关闭后 WebGL 可能变慢或不可用，页面会自动切换到简化显示。
- 通过菘蓝或白曜使用时，导入 HTML 后复制它们提供的「OBS 浏览器源」网址添加到 OBS。
- 设置里可以把显示方式手动切到「简化显示」，用于排查问题；网页地址后加 `?render=2d` 效果相同（OBS「本地文件」方式没法加参数，用设置切换）。

## 10. 数值目标与平衡模拟

模拟主播按每秒约 3 片有效拾取、优先朝反光挖的策略，另跑一组随机挖作对照：

- 无捣乱：标准档中位 2–4 分钟拔出；至少 80% 的模拟局能在 5 分钟内拔出。
- 接近窗口：从开始反光到可以拔针，中位 20–30 秒。
- 各效果拖慢（在接近窗口内对目标区域施加，中档）：一阵风约 15 秒，落叶雨约 40 秒，篮子炸了 20–30 秒，龙卷风 60 秒以上；结霜按手速估算，报告中注明所用手速。

脚本 `tests/balance.cjs`，结果写入 `tests/balance-results.json`。以上为工作量模型，不代表实播时长。

## 11. 实现结构

目录 `扫叶子/落叶寻针对决版/`：

| 文件 | 职责 |
|---|---|
| `assets/cute-atlas.png` | 从 v0.11 复制；叶片与木桶取自同一图集 |
| `src/layout.js` | 画面适配、坐标换算、图集提取（从 6 块扩展到叶片 + 木桶） |
| `src/camera.js` | 透视投影、屏幕↔世界换算、射线（纯逻辑） |
| `src/pile.js` | 3D 叶堆：堆叠、高度网格、射线点选、针、层数、露出比例、反光状态、快照（纯逻辑） |
| `src/effects.js` | 效果目录、三档默认值、参数校验、各效果对叶堆和对局的作用（纯逻辑） |
| `src/duel.js` | 对局状态、计时、比分、压哨、排队、贡献计分、惩罚牌堆、点赞累计、快照（纯逻辑） |
| `src/gifts.js` | 消息解析、礼物名归一化、去重、头像昵称提取、规则匹配（纯逻辑） |
| `src/render.js` | WebGL2 渲染：叶片、针、木桶、阴影、深度明暗、霜面、光带（预乘 alpha，透明清屏） |
| `src/render2d.js` | Canvas 2D 简化渲染，与 `render.js` 接口相同 |
| `src/fx.js` | 效果动画与粒子（只负责视觉，不改规则状态） |
| `src/ui.js` | 比分牌、横幅、说明牌、针旁标签、结算、惩罚卡、操作面板、设置页；页面内下拉框和确认框 |
| `src/audio.js` | 合成音效 |
| `src/obs-key-shim.js` | OBS 按键兼容 |
| `src/app.js` | 主循环、输入、存档、宿主通道的装配 |
| `src/shell.html`、`src/style.css` | 页面骨架与样式 |
| `build.cjs` | 内联全部资源，输出 `../落叶寻针-v0.12-限时对决版.html` |
| `试玩.html` | 带背景切换的试玩页 |
| `tests/*.test.cjs`、`tests/balance.cjs` | 自动测试与平衡模拟 |

纯逻辑模块不依赖 DOM，可以在 Node 里测试；效果的规则结果由 `effects.js` 决定，`fx.js` 只负责把结果播成动画。

## 12. 开发步骤

1. **2.5D 小样**：叶堆、镜头、捡叶、深度明暗、露出比例、拔针、反光。先在本机 OBS 浏览器源里确认透明合成和「交互」窗口的点选、按住都没问题，再交给用户试镜头角度和手感，确认后继续。
2. **对决规则**：计时、比分、压哨、结算画面、惩罚卡、排队、暂停、保存与刷新恢复、多页面存档规则。
3. **全部效果**：11 个效果的三档、礼物与点赞接入、横幅、说明牌、捣乱王／护驾王。
4. **收尾**：设置页（页面内下拉框和确认框）、Canvas 2D 简化渲染、音效、平衡模拟与数值校准、本机 OBS 全面实测、构建交付。

## 13. 验收

- **Node 测试**：
  - 叶堆：堆高与层数成正比、点选取最前面一片、移除后其他叶片不动、开局不露针也不反光、露出比例、反光区域包含针但圆心不等于针。
  - 拔针：阈值、按住时长、被盖回时清零、压哨。
  - 对局：计时、胜负、比分、排队顺序与合并、暂停冻结。
  - 效果：每个效果三档的数量、份数相乘但不升档、目标点、篮子炸了退回原位、龙卷风按深度上限卷针。
  - 礼物：名称归一化、重复名拒绝、去重、头像昵称提取、点赞累计与零头。
  - 存档：快照恢复不重复生效。
  - 成品：单文件、资源内联、脚本可解析、根节点透明。
- **平衡模拟**：见第 10 节，交付时报告实际模拟数据。
- **浏览器**：用内置浏览器通过本地 HTTP 打开实际交付的 HTML，WebGL 和 `?render=2d` 简化显示各检查一遍：
  - 捡叶与拔针、每个效果的三档画面、两种结算与翻卡；
  - 透明区域像素抽检，包括结算、暂停、打开设置这几个状态；1280×720／1920×1080／窄窗口的完整显示；
  - 刷新恢复、存储失败提示、模拟礼物去重和点赞累计、两个页面同时打开时的存档规则。
- **本机 OBS 实测**（会先征得你同意再操作 OBS，只用「测试」场景）：在 OBS 32.2.2 的「测试」场景加一个浏览器源，勾「本地文件」选择交付的 HTML，1280×720 和 1920×1080 各测一次，下面垫一个彩色背景源：
  - 透明区域能透出下面的画面，叶片边缘、阴影、反光和霜面没有黑边或白边；结算、暂停、打开设置时也不遮住整个画面；
