# 落叶寻针 v0.12 第 2 步：观众礼物效果 · 实现计划

2026-09-30。用户决定把原第 2、3 步对调：先做礼物效果，计时、比分、惩罚卡放到后面。设计依据是 `设计.md` 第 5、9 节，以及执行中确认的「叶子可以溢出」「护脸圈是透明实体」两条。第 1 步小样的镜头和手感先用默认值（60°、每层 4、1200 片）。

**执行方式**（用户要求加快）：模块按下面的接口分给子代理并行实现，每个模块自带 Node 测试，不做逐任务的多轮审查；最后由主会话组装，并在浏览器里实际验证。本目录不是 git 仓库，不做提交。全部测试：`node --test "tests/*.test.cjs"`。

## 总体做法

- **逻辑延迟生效**：效果触发后，先由 `EffectEngine` 算出结果，再按动画节奏生效。
  - 新落下的叶子在「落地时刻」才加入叶堆。
  - 被吹走、扫走、卷起的叶子在触发时立刻离开叶堆，由动画带走。
  - 这样画面上看到的就是叶堆里实际存在的，不会点到还在空中的叶子。
- **目标点**：取最近 20 秒内最后 8 次拾取位置的重心；还没捡过时，取叶堆上随机一点（`app.js` 通过 `getTarget()` 提供）。
- **坑**：当前高度比开局原始表面低 2 层以上的高度格（`pile.baseHeight`）。
- **落点检查**：所有加叶入口都经过 `app.js` 提供的 `adjustLanding({x,y,size})`。它负责护脸圈（把落点沿地面推到圈外），溢出不做限制。
- **画面范围**：叶堆的空间哈希和高度网格覆盖整个可见画面（45°–75° 下画面四角对应的地面）。落在画面外的叶子算溢出，照常存在，只是看不见。

## 模块与接口

### A. `src/pile.js` 扩展（子代理 1）

1. **构造参数 `bounds`**：默认 `{x0:-1200,y0:-450,w:2400,h:1600}`，替换原来按 `MARGIN` 算的范围。`x0,y0,w,h,cols,rows,hcols,hrows` 都由它得出，开局仍只在椭圆 `a,b` 里铺叶。
2. **`dropLeaf({x,y,yaw,size,type})`**：让叶子落在当前表面上。
   - 在叶片掩码内取 5×5 网格采样点（落在掩码里的点，至少取中心点）。
   - 支撑高度 = 这些点上已有叶片的最高 z；新叶 z = 支撑高度 + thickness，`depth:0`。
   - 用于效果落叶；开局铺叶仍用 `addLeaf`。
   - 返回新叶片。
3. **`removeMany(list)`**：批量移除。
   - 一次过滤 `leaves` 和受影响的哈希格，高度网格按全部被移除叶片的覆盖范围并集重算一次。
   - `maxZ` 重算一次，`version` 只加 1，并清空 `exposureCache`。
   - 返回实际移除的数量（不在堆里的叶片忽略）。
4. **`surfaceLeaves(x,y,r,n)`**：返回以 (x,y) 为圆心、半径 r 内的「表层叶片」，最多 n 片，按 (z,id) 从高到低排序。
   - 表层叶片的定义：中心点没有被任何 (z,id) 更高的叶片盖住。
5. **`isPit(x,y)`**：当前高度 < 原始表面高度 − 2 层时为 true。没有 `baseHeight` 时返回 false。
6. **`placeNeedleAt(x,y,yaw)`**：把针放在当前表面上，z = 针身采样点处 `heightAt` 的最大值 + thickness/2。`pulled=false`，`version++`，清空 `exposureCache` 和 `glintCenter`。
7. **测试** `tests/pile-effects.test.cjs`：
   - `dropLeaf` 落在最高支撑之上，且从镜头看可见，`pick` 能点到；
   - `removeMany` 的结果和逐片 `remove` 一致（高度网格、哈希、maxZ 相同），`version` 只增加一次；
   - `surfaceLeaves` 只返回未被中心覆盖的叶片，按顺序且不超过 n；
   - 挖坑后 `isPit` 为 true，未动处为 false；
   - `placeNeedleAt` 后针露出（exposure>0），再在针上方 `dropLeaf` 若干片后 `minCover` 增加；
   - 扩大后的范围内，远处（如 x=1100, y=1000）加的叶子也能被 `pick` 点到。
   - 原有 39 项测试照常通过。其中 pile-base 的「整张高度网格与暴力计算一致」在大网格下可能变慢，允许改为只检查原椭圆外扩 200 的范围。

### B. `src/gifts.js`（子代理 2，纯逻辑，UMD `LeafGifts`）

- **`normalizeName(s)`**：去掉首尾空白，全角转半角，转小写，去掉空白和常见符号（`·•・,，.。!！?？:：;；'"“”‘’()（）[]【】-_~～`）。
- **`parseGift(msg)`**：接受字符串（JSON）或对象，兼容 `data` 嵌套（字符串或对象），不是礼物时返回 null。
  - 取值：`name`（giftName／gift.name／gift.giftName／name）、`count`（count／giftCount／comboCount／repeatCount／gift.count，默认 1，必须是 1–100000 的整数）、`eventId`（eventId／msgId／id）。
  - `nickname`（nickname／userName／user.nickname／user.name，默认「观众」，截断到 24 字）、`avatar`（user.avatar／avatar／avatarUrl／user.avatarUrl／gift.avatar，只接受 http(s) 或 data:image 开头）。
  - 识别规则：`type` 含 gift／礼物，或者有礼物名。
- **`parseLike(msg)`**：从 count／likeCount／data.count／data.likeCount 取 1–100000 的整数；另外取 nickname，其余同上。
- **`Dedupe({windowMs=60000,cap=500})`**：`seen(id,now)` 已见过返回 true，否则记录后返回 false；无 id 时一律返回 false；可 `toJSON()` 和 `fromJSON()`，供存档用。
- **`matchRule(rules,name)`**：按 `normalizeName` 比较，返回第一条命中的规则或 null。
- **`duplicateNames(rules)`**：返回归一化后重复的礼物名列表（忽略空名）。
- **`LikeCounter`**：`{total,carry}`。`add(n)` 返回本次应触发的次数 `floor((carry+n)/step)`，余数留作 `carry`；`step` 由调用方传入；可 `toJSON()` 和 `fromJSON()`。
- **测试** `tests/gifts.test.cjs`：各种菘蓝和 WebSocket 消息样式、嵌套 data、非法 count、头像过滤、去重窗口和容量、名称归一化（全角、大小写、符号）、重复名检测、点赞累计与零头。

### D. `EffectEngine`（子代理 3，第二部分，依赖 A、B、C）

```js
new EffectEngine({pile,config,random,getTarget,adjustLanding,bucket,thickness,glintThreshold:()=>8})
```

- **参数**：
  - `bucket`：`app.js` 维护的已捡叶片列表，元素为 `{x,y,yaw,size,type,at}`，按拾取顺序排列。
  - `random`：可注入的随机函数（测试用固定种子）。
- **状态**：
  - `engine.state={frost:{layers,progress,lastClick},quick:{until,layers},sun:{until,center,radius,start},timeBonus}`；
  - `engine.pending`：按落地时刻排好的待生效变更；
  - `engine.queue`：场面型效果按 id 分队，同一效果一个接一个，前一个结束后 0.5 秒再上下一个。
- **`trigger(id,tier,portions,now)`**：按设计 5.1 的分类处理：
  - 数量型：份数合成一次效果；
  - 场面型：拆成 `portions` 个单次效果进入队列；
  - 叠加型：直接累加。
  - 返回 `{ok,visual}`，其中 `visual` 是给动画用的事件（见下）。
- **`update(now)`**：执行到期的 `pending` 和队列；结霜在停手 1.5 秒后每 0.4 秒回落 1 下；清掉过期的快手和阳光。返回本帧新产生的动画事件数组。
- **`frostClick(now)`**：结霜层数大于 0 时进度加 1；点满本层要求的次数时层数减 1、进度清零，最后一层破掉时发出 `frostBreak` 事件。
- **`canPick()`**：结霜层数为 0 时为 true。`pickLayers()` 在快手生效时返回档位的层数，否则返回 1。
- **`flushAll()`**：把所有 `pending` 立即生效（第 3 步存档会用到，测试也会用到）。
- **各效果的逻辑**（落点都要经过 `adjustLanding`）：
  - **drift**：`count×portions` 片新叶，落点在目标点周围半径 110 内，1.0–1.6 秒后逐片 `dropLeaf`。
  - **gust**：风向随机取左或右。从目标点上风侧 150–450 的表层叶片（`surfaceLeaves`）里取 `count` 片，立刻移除；再在目标点周围半径 140 内优先挑坑（`isPit`），没有坑就在目标点附近落下；0.8–1.4 秒后 `dropLeaf`。
  - **frost**：`layers+=portions`；每层要点的次数取当前档位的 `clicks`。换档也只影响之后新加的层。
  - **rain**：`count` 片新叶。七成落在坑里（从全部高度格里随机取坑格），不够时落在叶堆椭圆内随机点，其余三成落在整个可见范围里（允许溢出）；0.6–2.2 秒陆续 `dropLeaf`。
  - **burst**：从 `bucket` 末尾取 `count×portions` 片，按原位置 `dropLeaf`，0.5–1.2 秒后落地；木桶不够就有多少退多少。
  - **tornado**：路径从画面左或右外侧进入，经过目标点附近，持续 `seconds` 秒。
    - 沿路径在半径 `radius` 内收集表层叶片，最多 `count` 片，立刻移除。
    - 结束时把这些叶子撒进坑里，没有坑就撒在叶堆上。
    - 路径经过针（针中心离路径小于 `radius`），且 `pile.minCover()` 不超过 `needleDepth`、`needleDepth>0` 时，卷走针：落在离原位 ≥250 的叶堆内随机点（`placeNeedleAt`），再在针身上方 `dropLeaf`，直到 `minCover` 达到反光阈值加 2，或者加了 60 片为止。
  - **sweep**：取目标点附近 `count×portions` 片表层叶片（半径由 80 起，每次扩大 60，直到够数），立刻移除并加入 `bucket`。
  - **tailwind**：取目标点周围 `count×portions` 片表层叶片，立刻移除；它们被吹出画面，不进木桶。
  - **quick**：`until=max(until,now)+seconds×portions×1000`，`layers` 取该档位的 `layers`。
  - **sun**：光圈面积 = 叶堆椭圆面积 × `area`%；半径 = `sqrt(area% × a × b)`。圆心相对针中心随机偏移，距离不超过 0.6×半径（保证针在圈内），持续 `seconds` 秒。
  - **time**：`timeBonus += seconds×portions`（计时在第 3 步接入）。
- **动画事件**：
  - `{type:'fall',leaf,from:[x,y,z],to:[x,y,z],t0,t1}`：飘落叶、落叶雨、篮子炸了、一阵风、龙卷风撒落，每片一个事件；
  - `{type:'fly',leaf,from,to,t0,t1,into:'bucket'|'away'}`：扫一扫、顺风、龙卷风卷起；
  - `{type:'tornado',path:[[x,y],…],radius,t0,t1}`；
  - `{type:'gust',dir,center,t0,t1}`；
  - `{type:'burst',t0}`、`{type:'frost',layers}`、`{type:'frostCrack',progress,need}`、`{type:'frostBreak'}`；
  - `{type:'quick',until}`、`{type:'sun',center,radius,t0,t1}`、`{type:'time',seconds}`；
  - `{type:'needleToss',from,to,t0,t1}`。
- **测试** `tests/effects-engine.test.cjs`，用固定随机种子和合成掩码：
  - 每个效果中档的数量正确（落叶／移除片数、木桶退回片数、结霜层数与点击次数、快手时长与层数、阳光圈包含针、加时累加）；
  - 延迟生效：`update(now)` 到期前叶子不在叶堆里，到期后在；
  - 场面型排队：同一效果按顺序进行，不同效果可以并行；
  - 送多个只乘份数不升档：同一档位下 `portions:3` 的数量是 `portions:1` 的 3 倍；
  - 龙卷风按 `needleDepth` 决定卷不卷针；
  - 结霜阻止拾取并会回落；
  - `adjustLanding` 被所有落点调用。

### F. 组装与动画（主会话）

- **`src/fx.js`**（全局 `LeafFx`）：把动画事件画出来。下落叶片带翻转和阴影；飞出的叶片沿弧线移动；龙卷风是一根旋转的叶柱加风线；一阵风画横向风线；结霜是半透明冰面，裂纹随进度增加；篮子炸了时木桶先鼓起、抖动再弹开；快手是光标周围的金色光环；阳光是一道斜扫的光带加一个柔光圈；针被卷走时沿抛物线飞出。
- **护脸圈是透明实体**：
  - 落点：`adjustLanding` 把叶片在屏幕上的投影推出圈外；
  - 飞行中的叶片：每帧检查屏幕位置，进入圈内就沿半径方向推到圈边（在该深度沿镜头的 right／up 方向移动），看起来是绕着圈滑开；
  - 开局铺叶时，落在圈内的点重新抽样；开关圈、拖动圈、改镜头仰角时，把圈内的叶子移除后重新 `dropLeaf` 到圈外。
- **接入**：
  - 菘蓝 `SonglanPlugin.onGift`／`onLike`；没有 SDK 时连接 `ws://localhost:10030`，断线 3 秒后重连。
  - 按 `Dedupe` 去重，`matchRule` 找到规则后调用 `engine.trigger` 并显示横幅，同时累计捣乱王／护驾王分数（档位权重 × 份数，点赞不计）。
  - 点赞交给 `LikeCounter`，按设置触发效果。
  - 页面公开 `window.AutumnNeedle={receiveGift,receiveLike,getState}`。
