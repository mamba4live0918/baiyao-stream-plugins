# v0.11 自然避让与完整画面

参考原始插件 `../N.扫叶子-12.v6.html`：无堆积区按需开启，圆内拖动、右缘手柄缩放，叶子向两侧避让；调整后隐藏框。原文件未修改。

## 改动

- 新版无堆积区默认关闭，不预留固定的头部洞。保留需要时启用、调整和保存的能力。避让将整片叶子向左右移动，并给不同叶片留不同间隙，不把叶片齐整地贴在圆周上。
- 模拟互动和区域面板默认收起，H 或右下角“互动面板”展开；让正常直播画面中的叶堆完整露出。
- 场景固定为 1440×810 逻辑尺寸，按窗口完整等比适配；多余区域透明。画布、HUD、面板一起适配；输入坐标由画布实际位置反算，不直接拿窗口坐标捡叶。浏览器缩放窗口不会重新搬动针或叶片。
- 叶子生成、回填、恢复、调整尺寸时按完整旋转外接圆限制边界，保留安全距离。飞叶特效也在画布内显示完整物件。
- 素材不再按固定九宫格直接取图，先找完整连通叶片的边界，再保持原比例放入纹理槽，避免跨格叶尖被切掉。原 PNG 文件未修改。
- 保留四区对抗、拾取进度、1200层开局遮挡、线索门槛、搬针限次及找到即通关。
- 新版独立存储 `autumn-needle-natural-v11`；旧版 HTML 和进度不覆盖。
