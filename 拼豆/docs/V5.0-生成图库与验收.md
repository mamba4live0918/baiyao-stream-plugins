# V5.0：52 张生成图纸

日期：2026-09-24。

## 本轮范围

用户希望自行生成图纸，并参考小红书热门款式。访问搜索页后遇到登录要求，用户最初准备扫码，随后明确选择「暂时不要了」。因此停止小红书登录与检索，没有核实站内点赞、收藏或排名，也不把这些作品标称小红书热榜。

本版预设全部替换为自行生成、整理的 52 张图纸：猫兔 8、萌宠 8、甜品 16、人物 4、奇幻 12、花饰 4。旧图仍只用于已有存档兼容，不进入新预设列表。

## 生成资料

- 采用内置 `image_gen`，未调用 CLI/API 密钥路径。
- 完整提示词：`reference/generated-patterns/prompts.json`。
- 4 张透明源图：同目录 `animals.png`、`desserts.png`、`fantasy.png`、`floral.png`。
- 转换脚本：`prepare_generated_patterns.py`；实际游戏数据：`src/generated-patterns.json`。
- 实际格子总览：`交付/新图纸52款总览.png`。此图渲染自 JSON 豆格，不是高分辨率源图缩略图。

处理保留透明背景，按区域清除跨图集边界的小碎片，最近邻取格、每图最多 18 色且不抖动，保留一格透明边距。连通检查发现花环中心月亮与外圈相差一个连接格，补入相邻颜色的一个豆格，使成品可作为整体。原 PNG 未覆盖。52 张图案内容不同，831–1788 豆，全部四向连通，宽高不超过 46 格。

## 接入行为

- 新用户默认第一张新图，默认原色保留。旧用户保持原存档与颜色档位，首次升级打开新图库；旧作品标题增加「旧版进度」。用户当前相机 76/118 进度经浏览器刷新核对未改变。
- 图纸按原生网格居中，不随板格扩大而放大像素；板格不足时自动扩大，禁止缩到裁掉图案。
- 图纸卡片显示尺寸、原色数与用豆量。分类过滤替代旧类别。
- 新图色号注册为 G 系列，内置色库仍为 P 系列，自选色仍可使用十六进制。G 是游戏色号，不声称对应实体品牌。
- 全部颜色视图按本图需要颜色优先；当前用色过滤继续紧密排列。
- 自定义关卡默认采用新图库。存档包含完整格子、原色数据与来源标记，因此刷新和旧文件继续可用。
