# V5.6：自定义互动级别与双宿主演示

日期：2026-09-26。

## 自定义互动级别

- 九种互动效果分别管理级别；每种效果允许 0–20 个自定义互动级别。
- 可以添加、重命名、删除、启用或关闭单个级别。关闭保留规则；删除后不再参与礼物匹配。
- 每级别分别设置礼物名称及该效果原有的专属参数。除打翻托盘外，还可设置每份礼物的基础用量；礼物数量只乘命中级别的用量，不自动切换级别。
- 摇桌的力度和时长、升级拼豆笔的容量等按对应级别独立设置。打翻托盘是一次整盘散落事件，重复礼物合并；该效果每级别只设置每段连按次数与进度回落，不使用数量倍率。
- 升级时把旧轻、中、重三档迁入可编辑级别列表，保留礼物名称、用量和专属参数；旧规则原本启用但礼物名为空时，迁移后改为关闭，以保持不触发。旧存档的作品与进度应保持可读。

## 一条无配音无字幕综合演示视频

演示使用 `交付/拼豆-1.html`。一条视频依次呈现菘蓝安装、白曜安装、主要功能和九种互动。操作时不直播；鼠标放慢，每次点击后停 1–2 秒。交付原片不加配音或字幕。

1. 菘蓝整蛊插件：顶部「自定义插件」→在列表导入 HTML→点「预览」确认画面→复制 OBS 源地址→在 OBS「测试」场景添加「浏览器」来源，粘贴地址，宽高 1280 × 720。
2. 白曜重工 0.7.7：「插件」页→底部「更多插件与高级说明」导入同一 HTML→右侧「桌面预览」确认画面→点「OBS 浏览器源」复制链接→在 OBS「测试」场景添加浏览器来源，宽高 1280 × 720→回白曜把「白曜画面」拨到「已开启」。
3. 继续展示拼豆主要功能与九种互动效果，包括自定义互动级别、礼物名称、用量和各效果的专属参数；打翻托盘展示整盘触发和重复礼物合并。

菘蓝左侧直播间地址和 Cookie 状态在后期剪辑中打码。软件界面如发生可剪除的操作失误，接着完成流程即可。

## 交付与验收要点

- 先运行 `npm test`、`npm run build`，再用新页面实测级别新增、重命名、删除、开关、0 与 20 的边界、礼物名称/数量路由及效果参数；另测托盘整盘触发、重复礼物合并和连按/回落参数。
- 导入旧轻、中、重规则，检查迁移后的礼物名称、用量、专属参数与礼物效果；另以“旧规则启用但礼物名为空”验证迁移后关闭且不触发。确认原进度和成品仍可打开。
- 对菘蓝与白曜各自检查预览、OBS「测试」场景 1280 × 720 浏览器来源、白曜画面开关；不以安装演示代替真实直播礼物联调。
- 重新生成 `交付/使用说明.pdf` 并渲染检查。录制视频到 `交付/拼豆演示.mp4` 后，才运行 `python release.py`；脚本会打包 HTML、PDF、MP4 并逐字节核对。

本文件记录目标流程；具体通过项目以本次运行的测试结果和录制文件为准。
