# V5.3：画质设置（重点是熨烫后的 3D 成品）

日期：2026-09-25。

## 新增

设置 → 画面与操作 → 画质，两项各有「标准 / 高 / 超高」，默认都是「高」，随自动存档、命名存档和导出文件保存；旧存档读取为「高」。

### 成品 3D 画质（熨烫后的成品、作品库检视、下载的 GLB）

| | 标准 | 高（默认） | 超高 |
| --- | --- | --- | --- |
| 双面保孔：每颗豆孔/边分段 | 16（≤24 格 24） | 按豆数分配，20–32 | 24–48 |
| 熔面款：每颗豆表面细分 | 6（≤24 格 8） | 7–12 | 9–16 |
| 表面贴图（46 格板） | 1024 | 2304 | 3584（上限 4096） |
| 各向异性过滤 | 4× | 8× | 16× |
| 渲染像素 | 屏幕像素 | 屏幕像素 | 1.5 倍超采样 |

- 网格按顶点预算分配（高约 46 万、超高约 90 万顶点），大板不会失控。「标准」的网格与 V5.2 完全相同。
- 所有档位共同的改进：
  - 色调映射由 ACES 改为中性映射，豆色更接近色号（原来粉色、奶油色偏灰偏白）。
  - 熔面四款（澡巾、褶皱纸、毛巾、单面无孔）贴图加入豆与豆之间的浅缝和缝隙阴影，澡巾、毛巾款保留每颗豆轻微的圆鼓，能看出一颗颗豆。
  - 表面颗粒改为按世界坐标生成，分辨率越高越清晰，颗粒大小不变。
  - 双面保孔的孔壁、单面款背面凹孔深处略暗（预烘焙环境光遮蔽），孔更有深度。
  - 成品镜头拉近约 16%，画面里的成品更大。
- 选择熨烫方式时的小预览固定用「标准」，切换方式不卡；熨烫完成后按设置生成。在成品或作品库检视打开时改画质，会立即重建。
- 性能参考（云端 CPU，46×46 草莓抱抱猫，纯 JS 生成时间）：高档褶皱纸约 3 秒，超高约 6 秒；其他款更快。生成期间画面会停顿。超高档 GLB 约 48 MB（网格约 37 MB，其余是贴图）。

### 工作台画质（拼豆桌面）

| | 标准 | 高（默认，同旧版） | 超高 |
| --- | --- | --- | --- |
| 渲染像素 | 最高 1.25 倍 | 最高 2 倍 | 1.5 倍超采样，最高 3 倍 |
| 阴影贴图 | 1024 | 2048 | 4096，边缘更柔 |
| 板上豆子分段 | 16 | 20 | 32 |

切换时按当前进度重建工作台：已拼豆、掉落豆、托盘状态都保留。OBS 掉帧时建议选「标准」。

## 验证

- `npm test`：74 项通过（新增：三档网格精度与预算、未知画质回落为「高」、贴图颗粒与分辨率无关、画质设置的存档兼容与损坏拒绝）。

- `qa-v52.mjs` 回归通过。
- 目视对比（`tmp/qa-quality/` 与本文档同批截图）：双面保孔孔更圆、孔内更暗；熔面款能看到豆缝与表面纹理；颜色更接近色号。
