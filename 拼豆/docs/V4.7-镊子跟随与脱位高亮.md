# V4.7 镊子跟随灵敏度与脱位豆高亮

用户已澄清灵敏度指鼠标跟随的镊子。因此最终实现只保留工具跟随速度，不改布局拖动、滚轮或成品旋转灵敏度。

- 设置→画面与操作→镊子跟随灵敏度，0.25–3 倍，默认 1 倍；低档慢而平滑，高档更跟手。拼豆笔共用。
- 指数平滑按真实帧间隔计算，避免帧率改变手感。指针进入操作区时就位；按下鼠标时立即对齐落点，取放豆仍以实际鼠标位置命中。
- 设置进入自动保存与手动存档，旧文件默认 1 倍；非法导入值拒绝。
- 脱位豆使用蓝色光圈加白边，按物理姿态每帧更新，正对相机；与红圈错色、橙圈多余豆分开。
- 落地、刷新后高亮保留；点击直接移走后立即消失，仍不放入手里。二维降级的清理按钮也增加蓝色强调。
- 新的高亮用两组实例绘制，容量随掉落数量增长。

## 验证

67 项单元测试通过。qa-sensitivity-fallen.mjs 实测 0.25 倍与 3 倍跟随响应差异、点击对齐、设置保存/刷新、非法值回退；20 颗脱位豆光圈数量与模型一致，刷新不丢，逐颗点击移走后清除且手里仍为空，页面脚本错误 0。证据在 tmp/qa-sensitivity/。
