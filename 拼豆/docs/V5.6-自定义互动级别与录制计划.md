# V5.6 自定义互动级别与录制实施计划

> 当前目录不是 Git 仓库；按本计划在现有拼豆工程中测试、构建和交付。

**目标：** 九种互动的级别数量、名称、礼物与参数由用户管理；保留旧配置和存档；交付一支无配音、无字幕的真实安装及功能演示视频。

**设计：** 效果种类仍为九种，每种有独立的 `levels` 数组，允许 0–20 条。级别有稳定 `id`、可编辑 `name`、启停、礼物名称、用量和效果专属参数。新用户每种效果先有一条可编辑示例；新增级别默认禁用且礼物名为空，填好后启用。旧轻、中、重档依原 ID、礼物名、数值和参数迁移为可编辑级别。礼物数量只乘匹配级别的用量，并遵守既有单次上限。用户若选择“初始全部空白”，只调整新用户默认值。

**技术：** 原生 JavaScript、esbuild 单 HTML、Node test、Playwright、FFmpeg、ReportLab。最终 HTML 继续内联资源；交付路径是 `拼豆/交付`。

## 审查重点

- 新级别在刷新、导出/导入和命名存档后不能丢失。
- 旧三档礼物必须继续触发原效果，不因级别改名而改变路由。
- 禁用、删除、重复或空礼物名不可误触发。
- 打乱九种互动的演示顺序时，摇落、遮挡或托盘锁定不能掩盖后续效果。
- 视频不得出现开播动作；OBS 的场景必须是「测试」。
