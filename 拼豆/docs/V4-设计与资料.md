# V4：模式、颜色与熨烫重做

## 已确认需求与实现选择

- 用户要求自定义每关图案的关卡模式、全色自由模式、多档颜色精细度，并联网学习后重做五种熨烫。
- 保留单图模式。三种模式分别保存图案、进度和待存成品；切换前须完成库存托盘复原并手动拾取掉豆。
- 关卡支持预设、自定义图片、板格、换图、改名、排序和删除；每关独立颜色档位。挑战期间锁定编辑，完成所需遍数并熨烫后点击下一关。编辑列表重置该组挑战进度。
- 自由模式开放 256 色库及任意 RGB 自选色。没有目标时至少放一颗才可完成；成品用实际放下的颜色。帮助拼豆不执行；再拼一个冻结首次完成图案用于后续重拼。这是异步可选询问中给出的默认建议；用户未回复前沿此建议实现，可继续调整。
- 色彩档位 48、96、144、256、原色保留。原色为采样到板格后的颜色，不保证保留源图全部分辨率。低档和高档切换使用未量化 sourceCells，避免颜色反复转换损失。
- 原有 P01–P48 固定，扩展色使用后续 P 色号，自选色显示十六进制。全部为虚拟色库，不冒充实物品牌色卡。
- 每页最多 48 盒，按色号/色名/HEX 查询。原色提示使用一张文字图集与两个实例绘制组，避免逐色增加绘制批次。

## 材质实现

- 澡巾：连续封面、细颗粒微起伏，高粗糙度。
- 褶皱纸：跨色块不规则短折痕，几何起伏、法线和粗糙度共同改变反光；种子持久化。
- 毛巾：比澡巾更大的圈绒压纹和柔散射。模拟塑料布纹，非真实毛皮。
- 双面保孔：保持真实贯穿孔、颗粒肩部与厚度。
- 单面无孔：连续平整正面，背面带凹孔。三维模型保留正反差异。
- 连续表面边界采用一致法线，防止豆格缝上的伪高光。
- 现有成品会按新版材质重建，保留原色格、样式与种子；已下载的旧文件不变。
