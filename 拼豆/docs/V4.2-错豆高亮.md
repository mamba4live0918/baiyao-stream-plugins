# V4.2 错豆高亮

- 红圈标记错色豆，橙圈标记目标外的多余豆，白色描边保留与背景的对比；不修改豆子原色。
- 高亮从当前目标和已放豆派生。换色礼物、帮拼修正、取走、掉落、刷新及读取存档后重新检查。
- 无目标的自由创作不标错；自由模式重拼已冻结作品时正常检查。
- 修复多余豆被重复算进错色数量的问题；修复二维降级豆盒被画布遮挡的问题，并提供相同颜色的错误边框。
- 实测：61 项单元测试通过；qa-error-highlight.mjs 验证错色/多余、修正消失、礼物换色/帮拼、刷新、自由模式和二维降级，页面脚本错误为 0。
- 说明书更新；安装操作视频末尾新增 12 秒实录高亮说明。
