# V5.4：图纸随板格缩小 / 放大，重做豆盒倾倒动画

日期：2026-09-25。

## 图纸随板格缩放

- 52 张生成图纸在原生尺寸之外，各有 9 个版本（主体最长边 14、18、22、28、34、38、46、54、62 格）。它们不是把 44 格的图纸拉伸或压缩，而是从原来的高清图集（`reference/generated-patterns/*.png`）重新取样。
  - **缩小**：深色描边、眼睛优先保留，描边不断。
  - **放大**：原图里本来就有的细节，比如嘴、腮红、草莓籽、宇航员面罩高光，会出现在豆格里。
- 各版本只用该图纸原生的调色板，换尺寸后色号不变。每个版本都去掉 1–2 颗的孤立碎点，连成一整块（四向连通），四周留一格空位。
- 板格上限由 48 提高到 64，快捷尺寸为 16、20、24、30、36、40、48、56、64。
  - 在设置里换板格时，自动选放得下的最大版本；板格比最小版本还小时，板格自动用最小版本需要的格数。
  - 确认框显示新版本的预览图和豆数，例如「换成 30×30 板：图纸缩小为 29×30，共 544 颗豆（现在 1304 颗）」。换回 46 格即回到原生图纸。
  - 参考图卡片标出「缩小版 / 放大版」。
- 从图库选图时仍用原生尺寸，与 V5.0 行为相同；关卡里添加预设图，按「关卡板格」选对应版本。
- 草莓抱抱猫各尺寸豆数：16 格 131、20 格 224、24 格 333、30 格 544、36 格 799、40 格 1001、原生 46 格 1304、48 格 1437、56 格 1995、64 格 2642。
- 自定义上传的图片换板格时仍从上传时保存的 64 像素预览重新取样，最高 64 格。
- 数据：`prepare_pattern_variants.py` 生成 `src/generated-pattern-variants.json`，按调色板下标压缩，约 0.7 MB，原生 `src/generated-patterns.json` 不变。单 HTML 由 6.7 MB 增至 7.4 MB。

## 工作台性能（为 64 格准备）

- 已套稳的豆合批成一个实例网格绘制。正在落下、被摇松或掉落的豆仍是单独网格，行为与以前相同。
- 物理层改为只报告在动的豆和刚套稳的豆，不再每帧复制全部豆的位姿。
- 实测（Chromium 软件渲染）：46 格填满时每帧绘制次数由约 2900 降到约 290；64 格填满 2642 颗约 290 次。56 格及以上板上的豆子分段略降（每颗豆在屏幕上只有十来像素）。

## 装豆盒倾倒与复原动画重做

- **倾倒**：豆盒从左上到右下依次被掀歪，带回弹，最后歪斜地停着。每盒的豆沿抛物线倒到托盘前方的桌面，落地弹一下再滚一点，盒里只剩几颗。一共约 150 颗（按盒数分配）。
- **复原**：每完成一段，这一段的豆排队沿弧线飞回原来的盒子，边飞边转，落进盒子时盒子轻轻一弹、多装一些；盒子随进度慢慢摆正。五段完成后全部装满、摆正，并清理桌上的临时豆。
- 刷新或读取存档时如果托盘正处于散落状态，直接恢复成已散落的样子（已复原的段数对应的豆已回盒）。修复了以前刷新后豆盒不显示散落状态的问题（散落时会跳过画豆盒）。
- 纯脚本动画，不再用单独的物理世界，豆不会穿进盒子或被硬拉回画面内。只作装饰，不影响豆板进度和复原规则（仍需连按空格、停按回落）。
