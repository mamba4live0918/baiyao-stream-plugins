# V4.6 停放镊子与熨斗布局

用户指出图中的工具无法移动。原因是此前布局控制器只注册了豆板、豆盒、参考图和状态条，工具仍使用固定世界坐标；第二把镊子是始终跟随鼠标的操作模型。

- 新增 tweezers/iron 两个世界部件，分别支持双击解锁、拖动、拖角/滚轮缩放、双击锁定。熨斗和底垫为同一部件。
- 旧布局补齐默认工具参数，保持原有四部件坐标；新参数进入原有自动保存和存档。
- 动画中的熨斗使用相对停放组的局部坐标，完成后回到自定义停放位置与大小；底垫留在原位。
- 跟随工具只在豆板/豆盒操作区域显示，使用镊子时隐藏停放副本，避免空白区域双镊子。
- 双击解锁铁具与单击开始完成作品相区分，第二次按下立即取消待执行单击。
- qa-tool-layout.mjs 实测两部件拖动/缩放/锁定、刷新、无双镊子、慢双击不误开熨烫、动画回到自定义位置，脚本错误 0。64 项单元测试通过。
- DOM 参考图盖住工具时仍遵循页面层叠；先移开覆盖的参考图或点工具露出的区域。测试会选择真实可见工具位置。
