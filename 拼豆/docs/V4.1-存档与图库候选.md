# V4.1：进度存档与图库候选

## 已完成

- 操作后、15 秒间隔及页面关闭/隐藏时自动保存；显示最近成功时间。
- IndexedDB 保存最多 20 份命名进度，另有 1 份读取前恢复备份。覆盖、删除先确认。
- 读取前先成功写入备份，之后恢复完整图案、模式、关卡、落豆、托盘、遍数与设置；读取期间延后处理新到礼物。
- 导出 JSON 本地文件；即使 localStorage 不可写仍可导出。导入限 15 MB，严格校验后先预览，确认只新增存档，继续拼豆才替换画板。
- 保留绝对到期时间；手持未放下豆不计进度。已完成作品库不随进度文件迁移。

## 图纸候选（尚未替换正式预设）

从 https://kandipad.com/fuse-bead-patterns/popular 的前两页筛选出 52 张原生像素范围不超过 48×48 的现成作品，裁去空白边缘，不重新绘制图案。完整来源、作者、尺寸、浏览近似值、点赞和采集日期保存在 reference/热门图纸候选/candidates.json。HTML 预览逐张显示作者与来源链接；静态总览用于快速评估。

许可来源：https://kandipad.com/sharing-distribution ，CC BY-NC-SA 4.0。原站热度为 2026-09-24 页面快照，浏览数带 K 的按千次近似值记录。候选约 2200–8100 次浏览，不声称全网排名。

已向用户提出用途选择：非商业测试版 / 明确可商用素材替代 / 用户提供授权图纸。尚未收到选择，所以当前交付只加入存档；热门候选没有装入礼物变现直播版。候选预览中的图纸转换内容沿用同一许可，并保留署名。
