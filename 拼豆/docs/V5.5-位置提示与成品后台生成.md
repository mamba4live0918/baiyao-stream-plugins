# V5.5：拿豆时位置提示、成品后台生成、说明书更新

日期：2026-09-25。

## 拿豆时位置提示

- 手里拿着某个颜色时，板上还空着、需要这个颜色的位置会闪烁：外圈白边，内圈是豆的颜色。放下一颗就少亮一个。
- 遮图纸期间、或关闭「半透明提示与色号」时不亮，不会绕过整蛊礼物。
- 设置 → 画面与操作 → 直播画面 →「拿豆时提示对应位置」，默认开启，随存档保存；旧存档读取为开启。
- 实现：两组实例网格（`workbench-scene.js` 的 heldGlow），只在拿的颜色或空位变化时重建，脉冲只改透明度。

## 成品在后台线程生成

- 熨烫动画一开始，就在后台线程（Web Worker）生成成品网格和表面贴图数据。算好后整体转交给主线程，主线程只负责上传显卡、创建检视器。
- 动画结束时还没算完，会显示「正在生成成品 3D 模型…」，画面不会停住。作品库检视、在成品打开时切换画质，也走后台线程。
- 后台线程代码单独打包成字符串内联进 HTML（约 0.28 MB），运行时用 Blob 启动，不依赖外部文件。已验证用 `file://` 直接打开时能正常启动。如果后台线程不可用或出错，自动改回在当前线程计算，结果相同。
- 表面贴图改用 DataTexture；环境光遮蔽和粗糙度合并为一张贴图（R 通道是 AO，G 通道是粗糙度），超高档少占约三分之一的贴图内存。行序预先上下翻转，外观与 V5.3/V5.4 一致。
- 新增：`src/finish-worker.js`（后台线程入口）、`src/finish-worker-client.js`（调度与回退）。另外 `build.mjs` 先打包后台线程再内联；`finished-viewer.js` 新增 `buildFinishedData` / `surfaceMapData`，`createFinishedViewer` 支持 `prepared`。
