# 淘金 · 簸箕版 · 使用说明（V0.4 · 2026-10-12）

画面里只有一只竹编簸箕，没有场景，透明底。观众送礼物 = 送一袋矿砂，麻袋上写着送礼人的名字，掉进簸箕里炸开，金子沉在沙底。你用鼠标端起簸箕淘洗，洗出来的金子自己飞到右边的「淘到」数字牌。观众可以捣乱，也可以派小偷来偷金子。

## 文件

| 文件 | 用途 |
|---|---|
| `淘金-簸箕.html` | **插件本体**（单文件，three.js、字体、程序都在里面，离线可用，透明底） |
| `淘金-簸箕试玩.html` | 试玩页：可以切换深色、浅色、棋盘格、直播背景，自带试玩面板和自动演示 |
| `字体许可-糖圆体-OFL.txt` | 内置字体的许可，和白曜内置字体是同一份 |
| `簸箕版/` | 源码和构建脚本（直播用不到） |

## 放进 OBS

1. 新建「浏览器」来源，勾选「本地文件」，选 `淘金-簸箕.html`，宽 1920、高 1080。
2. 簸箕默认在画面下方正中，左边是力度条，右边是数字牌。要挪位置或缩放，到设置的「外观声音 → 取景框 / 镜头远近」里改。
3. 在来源上右键选「交互」，在交互窗口里用鼠标玩。

## 怎么淘（只用鼠标左键）

- **按住画面任意地方，就端起了簸箕**。
  - 左右拖 = 晃簸箕，里面的水会来回荡。
  - 往下拖 = 把前口压低，水带着沙从前口冲出去。
  - 松手后簸箕自己放平。
- 左边的**力度条**：
  - 灰区：晃得太轻，沙子不怎么动。
  - 绿区：刚好，冲得最稳。
  - 红区：太猛，露出来的金子和靠近前口的金子会被甩出去，就丢了。
  - 不想丢金子，可以在设置「玩法 → 难度」里关掉甩出。
- 金子露出来、洗干净一会儿，就**自己飞到右边的「淘到」数字牌**，记在送矿观众的名下（矿主榜）。
- 实测参考：好好淘（绿区，往下压一点），一袋矿大约 15–20 秒就能冲干净。

## 观众的互动

每种互动都能自己定 1–12 档；礼物数量只放大带 × 的那一项，**不会升档**。

| 互动 | 效果 | 你怎么应对 | 礼物数量放大 |
|---|---|---|---|
| 加矿砂 | 一袋袋矿砂掉进簸箕炸开，里面有金片、金块，按几率出狗头金 | 淘就行 | 袋数 |
| 扔石头 | 石头砸进簸箕：压住沙和下面的金子，簸箕也变沉、晃不动 | 点石头，把它扔出去 | 石头数 |
| 倒泥水 | 泥水泼进来：水变浑，沙子变黏，金子看不见也收不上来 | 多晃一会儿，水就清了 | 持续时间 |
| 撞簸箕 | 隔一会儿撞一下，撞之前会有提示和「嘀嘀」声 | 听到提示就按住鼠标稳住；没按住就被撞得乱晃，露出来的金子可能被撞飞 | 持续时间 |
| 小偷 | 浣熊跳上簸箕帮沿，溜到后角，从你淘到的金子里偷一把，再跑掉 | 点它抓住（偷到的全部追回）；或者使劲晃，把它甩下去（金子掉回来，但太猛金子也会甩出去） | 偷的比例（最多六成） |

- 同一种持续型捣乱叠加，最多持续 60 秒。
- 小偷最多同时两只。

## 设置

把鼠标移到画面上，右上角会出现齿轮（停 2.5 秒自动隐藏）。也可以按 S，或者双击簸箕外面的空白处。Esc 或点面板外面关闭。

- **玩法**：说明、难度（太猛会不会甩出金子）、清空簸箕（淘到的金子保留）、打开试玩面板。
- **互动档位**：每种互动的档位名称、参数、默认档；点「▶ 试」可以试一下。
- **接入规则**：
  - 「接收真实直播事件」**默认关闭**，确认连接正常后再打开。
  - 指定礼物表默认是：小心心、玫瑰、人气票对应三档加矿砂；比心对应小偷；抖音对应扔石头；棒棒糖对应倒泥水；加油鸭对应撞簸箕。
  - 其他礼物：按单价分档加矿砂。
  - 弹幕公投：偷、石头、泥、撞，凑够 3 个人就触发。
  - 点赞蓄力：攒够 200 个赞送一袋普通矿。
  - 防刷屏保护。
  - 白曜里配置的规则动作不受接收开关影响。动作 id 就是互动名：ore 加矿砂、rocks 扔石头、mud 倒泥水、bump 撞簸箕、thief 小偷。value 选第几档，repeat 放大幅度。
- **外观声音**：画质（精致 / 均衡 / 省电）、装饰动画（开启 / 跟随系统 / 关闭；关闭后不再镜头抖动）、镜头远近、取景框、矿主榜和大盗榜、操作提示、音效和音量。
- **存档**：
  - 淘到的金子、矿主榜、大盗榜自动保存。
  - 试玩面板、自动演示、档位试用送来的金子照常计数，但不进榜单。
  - 试玩页的存档单独一份。
  - 旧存档读不出来时只提示，不会覆盖它。
  - 存储键是 `taojin-bj.v1.*`，和之前的 3D 版互不影响。

## 已验证 / 未验证

**已验证**（本机 Chromium 显卡渲染，自动化脚本截图和数值检查）：

- 透明底：读取实际合成后的像素，画面上方 100% 透明，四角 alpha 为 0。
- 加矿砂炸开、晃簸箕冲沙、金子自动飞到数字牌、太猛甩出金子。
- 扔石头（点掉）、倒泥水（变浑、变清）、撞簸箕（提示 → 按住稳住 / 没按住被撞）。
- 小偷：偷走、点中追回、晃下去追回。
- 自动演示连续玩 3 分钟：14 袋矿淘出 61.6 克，没有报错。
- 设置面板、试玩面板、规则编辑都改过一遍。
- 一帧约 6 毫秒；淘洗模拟固定按每秒 60 步算，屏幕是 30 帧还是 144 帧，淘得一样快。
- 第一次出现麻袋时的卡顿已消除，只剩 8 毫秒左右的一下。
- 单元测试：26 项通过，包括淘洗模拟的沙量守恒、水量平衡、泥水和石头的影响。

**未验证**：

- 真实 OBS 交互窗口里拖动的手感。
- 真实直播礼物和白曜/菘蓝 SDK 的真实字段。
- 其他电脑和显卡上的帧率。

建议先在 OBS 的「测试」场景里加来源试一次。
