# 五款透明互动增强版 V1.0

打开 index.html，顶部切换五款插件，右上切底色检查透明效果。插件本身仍为透明，图片/代码/样式全部内联。单独打开 plugins 文件夹中的 HTML 也可使用。

每款左下角「完整设置」提供玩法参数、外观声音、礼物接入、自动存档与备份。管理时会暂停游戏，关闭后手动继续。右侧快捷按钮用于模拟，不需要开直播即可体验。

| 玩法 | 基本操作 |
|---|---|
| 快递分拣 | 拖包裹到同色分拣口；选中后1/2/3也能投递 |
| 深夜异常便利店 | 观察顾客/人影/标签；A正常结账、D拒绝异常 |
| 魔女炼药锅 | 两份材料入锅，按住搅拌/空格，绿区松手 |
| 地下城救援队 | A/D或方向键移动，空格跳跃，J挥剑 |
| 危楼叠叠乐 | 空格/按钮落家具，看准中心线；P暂停 |

## 接入与恢复

在完整设置的「礼物接入」添加并保存礼物名、效果、单件量。页面优先识别菘蓝SDK；无SDK则手动连接本机端口（默认9910）。勾选接收真实礼物后才会执行收到的事件；刷新默认关闭接收。有ID的重复事件去重，宿主需要提供连击增量。

暂停/待开始期间礼物进入有上限候场，继续后按序执行。离开、刷新不会重播旧候场。自动恢复会先询问继续或新开；继续后保持暂停。换环境用JSON备份导入，先预览再确认。每款只能保留一个接收与写入的实例。

新增动画、每款参数范围、升级事项和具体验证范围见《升级说明-V1.0.md》。当前已经实现SDK与本机通道，不再是只有模拟按钮的版本，但真实平台送礼和OBS现场效果尚需联调。本次网页验证为本地HTTP，未冒充所有电脑、浏览器及file://方式都已测试。

推荐桌面1280×800及以上。窄屏会缩放；未做实体手机验收。老试玩包V0.1单独保留，本包不会包含源码、测试或旧包。
