# 快递分拣 · 3D 版

## 最新：自定义同场数量（2026-10-29）

操作修正：手动抓取不再要求上方没有物件，鼠标能点中的未投递物件都可拖出；抓取期间临时关闭该物件碰撞，松手恢复。胶带件和盲盒也可拖动；不拖动的短点继续拆胶带/开盲盒。批量加件保留当前镜头，只有手动点击「查看整堆」才缩放到整堆范围。原尺寸数万件在有限场地内仍会形成很高的排列堆，这和真实散落物理不同。

拿取修复验证：81项Node测试通过；内置浏览器在1200件原尺寸多层箱堆中，直接抓取诊断为“被上层压住”的箱子并投递，剩余1200→1199、已收0→1，控制台无错误。

「测试 → 场上上限（可自定义）」及「参数 → 同时在场件数」支持 **1–50000**，保存后生效。「测试 → 加件数量」也支持1–50000，点击「直接放到场上」会生成真实的独立场上物件，不放进货车队列。超过当前上限的请求会显示实际接收量，应先提高上限。货车方式仍按卸货速度进入场景。

超过500件的直接生成按帧分批完成；静止物件使用GPU实例合批和固定碰撞体，每件保留自己的编号、位置、品种及状态。抓取、无人机、胶带等互动会恢复该物件的动态物理；抓取支撑、踹桌和爆炸采用局部解冻，不同时模拟数万件的整体坍塌。停止的普通物件会重新合批。清空或切换玩法会取消未完成的生成。

「本次物件大小」可设0.1–1倍，默认1倍保持原尺寸；一万件原尺寸会堆得很高，0.3倍适合在原场地看密集堆积。「查看整堆」手动调整取景，「恢复普通取景」返回原画面；尺寸只作用于本次直接生成的物件。

实测内置浏览器：12000件垃圾同时在场、排队0；手动抓取恢复局部物理，操作采样约51 FPS（单次采样，不代表所有机器或所有时刻）；助手分拣5件后场上11995、已收5；清空归零、切换快递并生成1000件成功，控制台无错误。静止场景按既有节能逻辑约12 FPS。设置范围上限50000，未声称已完成50000件整场性能实测。设置存储键升级为kd-3d-config-v7，保留旧设置迁移。

## 2026-10-29：观众驱动无尽模式

经典俯视布局的快递筐/垃圾桶背后增加无渲染的空气墙与托底，覆盖桶排至传送带前缘之间的遮挡区，落到这里的物件会停在桶口高度附近；不封桶口、不挡前方漏桶滑槽，切换玩法时碰撞体随桶组启停。柜台布局已有实心柜体，沿用原碰撞。新增真实Rapier落体测试确认背后托住、桶口可通过。

同日修复连续上货堵塞：入口堆货台按真实物件数及卸货预留占位限制容量（经典24件、柜台8件），避免薄片/异形垃圾不断挤进入口。传送带上持续1.5秒没有明显位移的货物会自动抬送到台面较空处；被压住时先搬最高层，保留原物件及全部计数。新增容量、停滞识别、堆叠疏通回归检查。浏览器完整物理模拟验证150件垃圾卸完、入口清空、总量150不变；模拟推进时间不作为实际帧率结果。

默认无尽模式：空场等待，只通过观众互动或本地测试按钮加件；清空后继续等待，累计已收保留，不再过关或超时结算。管理面板「玩法」内可关闭无尽，使用旧关卡。

「又来一车 / 又来一车垃圾」的规则数值及档位件数支持 1–10000。货车批次按计数排队，场上同时出现的物件由「参数 → 同时在场件数」控制（最新范围见上节，初始默认150）。清出空位后继续卸货。总待处理量最多100万件；达到总量上限会提示实际接收数。封筐秒数、踹脚次数等其他参数仍使用各自范围。

「测试 → 批量堆积预览」可填写件数并选择「货车加件」或「直接堆到台面」。后者只补到当前场上容量，用于快速观察堆满效果。所有测试按钮均为本地模拟。

无尽模式「清空重开」需点两次；清空重开、切换玩法、刷新均开始新的统计。只保存设置，不保存本次物件和队列。设置改存 `kd-3d-config-v6`、规则改存 `kd-3d-rules-v4`，读取上一版设置，保留旧键和原有经典视角。

验证：71项Node测试通过。内置浏览器实测垃圾模式一件处理后回到等待且已收=1；场上150件仍接收10000件，剩余=10150；帮助收走5件后场上补回150、队列减少5；互动规则输入10000测试完整加入。真实直播间与OBS接入仍未联调。

## V2.0（2026-10-03）

打开上一级目录的 `快递分拣-3D版.html` 即可。单文件，three.js、Rapier 物理、25 种垃圾模型、贴图、OBS 按键兼容脚本全部内置；背景透明，直接做 OBS 浏览器源或导入菘蓝 / 白曜。给主播看的说明在分享包的《使用说明》PDF 里，本文件是开发说明。

## V2.0 做了什么

设计文档：`开发资料/设计文档/superpowers/specs/2026-10-03-快递3D-V2-垃圾分类-design.md`；实施计划：`…/plans/2026-10-03-快递3D-V2-垃圾分类.md`。

- 垃圾分类玩法（4 个国标分类桶、25 种程序生成的 3D 垃圾、品种开关与改分类、国标 / 上海叫法），两种玩法各一套关卡。
- 分错一变二（任何原因落进错筐都翻倍；抽查期间一变三；件数上限；未识别的件只弹出）。
- 整窗渲染 + 整窗物理：画布铺满窗口，分拣台用 `camera.setViewOffset` 框进「分拣台位置」；窗口四边是视锥侧面的 HalfSpace 隐形墙，另有后墙和无限大地面；可切回「只在地台上」。
- 主播露头圆：屏幕圆 → 从相机射出的凸包圆锥碰撞体（碰撞组只挡物件），接地阴影在圆内丢弃像素，署名标签避开。
- 新互动：抽查（audit）、刁钻垃圾（tricky，快递模式按 truck 执行）、捣乱无人机（prank，第二架无人机）。
- 互动分档（`src/tiers.js`）：12 种互动各有一组档位，数量由主播定（1–12 档），名字可改，其中一档是默认档；每档带这种互动的全部参数（数量、点几下、同时几个筐、倍数、飞行速度、力度……，见 `TIER_PARAMS`）。规则用档位 id 记住选的档，`''` = 默认档；删掉的档回退默认档。礼物个数只乘数量，不自动升档。白曜动作可带后缀选档：`seal:重`、`封桶·超重`、`kick：3`（数字 = 第几档，从 1 数）。说明牌只给明确选了档的规则写档名。V1.0 的 `fx` 参数迁移进默认档。
- V1.0 问题修复：见设计文档第 1 节；另修了标签跳动动画覆盖定位、整窗后堆货台射线撞墙导致货车不卸货。
- 加速、抽查按送达顺序排时段（`src/timed.js`），每段用自己的倍数和署名；封筐、漏筐叠到同一个筐时点的下数取大的。
- 存储：设置 `kd-3d-config-v4`、规则 `kd-3d-rules-v3`；第一次打开读入 V1.0 的 `kd-3d-config-v3`、`kd-3d-rules-v2`，之后不写旧键（V1.0 关页面时会按自己的格式整份重写设置，共用键会冲掉 V2.0 的分档）。

## 源码结构

| 文件 | 内容 |
|---|---|
| `src/main.js` | 场景、物理、循环、面板、直播接入（集成文件） |
| `src/config.js` | 设置默认值、范围收紧、V1.0 迁移、导入导出（纯逻辑） |
| `src/modes.js` | 两种玩法的筐、槽位、文字、12 种效果名、白曜动作别名、关卡字段 |
| `src/rules.js` | 互动规则默认值与校验 |
| `src/timed.js` | 限时效果（加速、抽查）按到达顺序排队的时段 |
| `src/tiers.js` | 互动分档：参数表、默认三档、清洗与迁移、按 id / 名字 / 第几档找档、白曜动作档位后缀 |
| `src/garbage-catalog.js` | 25 种垃圾、分类、原因说明、筐名方案、覆盖设置 |
| `src/garbage-models.js` | 25 种垃圾、大垃圾袋、泥、塑料袋层、桶标签的程序模型 |
| `src/mistake.js` | 分错判定（收下 / 只弹出 / 翻几倍）与统计 |
| `src/view-geom.js` | 视口偏移、视锥平面、圆锥凸包点（纯矩阵运算） |
| `src/tex-pool.js` | 按观众名生成的贴图的引用计数缓存 |
| `src/head-editor.js` | 露头圆编辑界面 |
| `src/page.html` | 页面与样式（`__INLINE_BUNDLE__` 处内联打包后的脚本） |

## 构建与测试（在本目录运行，借用拼豆工程的 esbuild 与 Playwright）

- `node build.mjs`：开发版，写到 `qa/out/快递分拣-3D版.html`，不动交付文件。
- `node build.mjs --release`：正式版，覆盖上一级目录的 `快递分拣-3D版.html`。
- `node --test "tests/*.test.js"`：纯逻辑单元测试。
- `node qa/e2e.mjs all`：浏览器验收（smoke、texleak、bounds、head、double、fixes、newfx、garbage、tiers）；默认测开发版，`QA_TARGET=release` 测交付 HTML；`QA_GL=gpu` 用显卡渲染。
- `node qa/filecheck.mjs <HTML 绝对路径>`：用 file:// 直接打开（不经网页服务器）跑两种玩法、12 种互动、分错翻倍、透明背景、无外部请求。
- `node qa/upgrade.mjs`：同一来源里 V1.0（取归档）→ V2.0 → 退回 V1.0 → 回到 V2.0，检查迁移和互不覆盖。
- `QA_HTML=<相对快递分拣文件夹的路径> node qa/e2e.mjs all`：测任意一份 HTML（如分享包解压出来的）。
- `node qa/gallery.mjs`：垃圾模型图鉴截图。`QA_GL=gpu node qa/perf.mjs`：粗测单帧耗时。
- `node qa/manual.mjs <pdf>`：拍说明书截图并打印 PDF；`QA_GL=gpu node qa/video.mjs <mp4>`：逐帧录演示视频（需要 WinGet 装的 ffmpeg；`VIDEO_FROM=秒` 只从某一秒开始出帧，调单段用）。
- Playwright 1.58 默认浏览器没装，`qa/harness.mjs` 借用本机 `ms-playwright/chromium-1223`。
