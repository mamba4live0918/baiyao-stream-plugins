# 就差一件下班 · 情绪互动版 V1.0

先打开「就差一件下班-预览.html」，点击「先看20秒」，即可自动演示“最后一件→小王加塞→阿橙救场→关门又被截住→最终下班”。演示标记始终显示，退出或切走页面会取消演示并恢复正常进度；演示不写入正常存档。

自己玩只需要把包裹拖进同色筐。默认10件，清空后还有3秒关门倒数；期间新包裹能打断关门。门完全关闭才算下班。分错、漏接会返工，工作量不会凭空减少。

观众只有三种直接互动：

- 不准下班：默认追加8件，立刻增加剩余数量，并让一批署名包裹同时入场。
- 这个也帮我收一下：追加1件超大包裹，同样计入剩余工作量。
- 别怕，我来救你：机器人最多清掉5件；包括候场工作，按实际数量反馈。正在拖动的包裹保留给主播处理。

每次大字显示观众昵称、加塞/救场数和情绪台词，搭配车辆、机器人、计数弹跳和合成音效。结算点名加塞最多和救场最多的昵称。

右侧署名留空时采用示例名字；正式事件使用事件中的观众昵称。左下完整设置可设置每班3–40件、声音/动画/画面位置、礼物规则与备份。真实直播接入沿用菘蓝 SDK 或本机9910通道，需要现场联调。本页右侧按钮为本地模拟，不代表观众真的送礼。

总剩余上限120件，单班累计最多2000件；超量按实际可接收数量反馈。正常存档与原来的快递版隔离。复制/分享只需要独立 HTML，素材、动画、音效代码全部内联；预览页的底色不属于插件本身。

## 验证（2026-09-27）

10项自动检查通过，包含最后一件追加后的真实工作量、关门被打断、救场实际计数、暂停、返工、容量、存档一致性、文件资源内联和旧存储键隔离。

本地HTTP浏览器实测：手动投递10→9，追加8件9→17，正确显示“小王寄来的”；继续实测只剩1件时加塞8件，剩余立即变为9件；自动演示完整结算22件、被拦2次，小王加塞16件、阿橙救场13件；结束演示正常班次仍为原来的10件。已检查透明页面与错误日志。未把本地HTTP测试当作file://、OBS或实际直播通路实测。
