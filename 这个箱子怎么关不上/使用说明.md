# 这个箱子怎么关不上 · 第 1 步手感样机

双击 **试玩.html**。左上角展开「试玩小面板」，点「压 → 松 → 拉练习」可直接试两只抱枕。右上角「看直播时的样子」隐藏试玩控制。

只用鼠标：

1. 把两边的行李拖进箱子上方，松手。抓中间更容易平放，抓一头会垂下来。
2. 在金色拉头前面、被顶起来的那段箱盖上按住；可按着左右移动。
3. 松手，马上抓金色拉头向右拉。拉头卡住时，红色轮廓和名字会指出是谁顶住了。
4. 再按、再松、再拉。也可以从缝里露出的部分把行李拎出来，留到下一箱。
5. 拉到头后自动寄走，新空箱回来，待装行李保留。没有关卡和倒计时。

猫探头时点猫头让它缩回去；帮手和绑带可以沿箱盖拖着挪。试玩里的帮手、打气、抽真空按钮只是本地手感实验，尚未接真实互动。

「手感调节」可调整容纳高度、允许缝宽、拉链强度、每种行李的软硬和回弹、力度爬升、帮手重量、自动收尾阈值及箱子长度。支持恢复默认和复制 JSON。

正式透明文件是 **这个箱子怎么关不上.html**，图像、脚本和样式均内置。鼠标移动后右上角显示设置；可以编辑脸框或切换猫爪/手套。刷新不自动重放旧互动。失焦/隐藏暂停；回来点击画面或恢复焦点继续。

素材预览：**源码/assets/预览.html**，包括压扁、弯盖、随机 200 件与三种底色。原创 PNG、锚点、生成提示词分别保存在 **源码/assets/src/**、**manifest.json**、**生成记录.json**。共用的猫爪、手套、帮手和被拎猫也已保存到指定共用目录。

本阶段交付是手感与画风确认版。完整待装堆、行李牌、头像、弹幕/礼物接入、音效、完整设置与一场存档按后续步骤完成。未验证真实 OBS。旧试玩目录保留，到第 5 步打包后再归档。

验收证据位于 **源码/qa/步骤1/**：单元测试、真实鼠标检查、20 秒操作视频、六尺寸截图、透明脸框检查、素材预览和素材总览。
