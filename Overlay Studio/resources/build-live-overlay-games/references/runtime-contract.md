# 透明直播运行约定

## 显示与输入

- html、body、舞台背景透明。Canvas 2D清屏保留alpha；WebGL创建时开启alpha并使用透明清屏色。仅删除CSS背景不足以证明画布透明。
- 棋盘格放独立预览容器或显式预览模式。普通输出不能带棋盘格、网站导航、整页卡片或调试面板；实体、必要HUD和主动打开的设置可有底色。
- 按宿主尺寸布局，写明逻辑坐标、缩放和输入坐标换算；DPR提高分辨率不能改变碰撞坐标。处理窗口缩放，避免对象凭空消失。
- 鼠标、触控和键盘按玩法选择。处理pointercancel、失焦和暂停，清除拖动和按键状态。输入框打字不触发游戏快捷键。
- CSS pointer-events只影响网页命中，不能保证穿透宿主窗口；穿透需求依宿主能力验证。

## 时间与生命周期

- 一个动画循环，时间步长有上限。复杂碰撞用固定步长和有限补步，不补算数分钟的后台时间。
- 区分待开始、运行、暂停、结束。暂停冻结物理、计分触发、倒计时和临时效果；只冻结玩家属于游戏效果，不等于暂停。
- 新项目默认隐藏时暂停，可见后等待手动继续。浏览器源可能不发送visibility事件，切场景需在宿主验证。用户要求后台继续时明确计时和帧率策略。
- 重开清空本局对象、临时效果和候场。销毁时清理监听器、计时器、连接；重复开始不会多注册循环。
- 设置页是否暂停按宿主约定；参数明确立即还是下一局生效。恢复存档后保持暂停。

## 运行预算

活动对象、粒子、DOM提示、日志、队列和去重缓存均有上限。先减少特效，再控制生成速率；不为视觉预算悄悄损失业务数量或提前计分。容量不足明确拒绝、合并或候场。

临时效果定义持续时间和叠加策略（刷新/延长/取最大/互斥），数值检查NaN、上下限和无效输入。限制依据玩法，不把某个例子的常量硬套所有游戏。

## 离线与保存

- 单HTML离线版不能依赖CDN字体、远程import或file下的fetch。大素材可随资源包提供，尊重用户交付形式；保留库和素材许可证。
- localStorage读取、解析和写入都可失败并降级；键按插件命名、配置带版本；导入先校验与预览。
- 默认只保存设置及明确要求的游戏进度。**不保存并自动重放礼物候场或未结算外部命令**。可靠事务恢复需另行设计持久化事件账本与幂等处理。
- 自动播放可能受阻；默认低音量或静音，提供开关并通过用户交互解锁音频。失败不阻止游戏。
