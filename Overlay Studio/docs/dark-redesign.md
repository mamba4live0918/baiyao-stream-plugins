# 1.1.0 黑色工作台

用户要求黑色底色，并认真重新设计整个UI。此版本视觉规范替代初版浅色概念；功能、IPC、生成权限和数据目录保持原有约定。

参考图：../design/dark-concept.png（内置Image Gen生成完整主界面概念）。
设计：黑色#090b0c、炭灰#121617、细分隔线#292e2f、白色主字和灰色副字；浅柠檬绿#c5f17c仅用于主操作、选中项和状态。侧栏218px，桌面表单365px，剩余宽度优先给预览。

重新组织：紧凑品牌/导航、任务导向标题、独立创作简报、独立灵感列表、大型深色棋盘预览、横向闲置进度、统一项目库/设置/弹窗。规范内容由安全的Markdown组件排版，支持列表和表格。

实现差异：保留真实禁用状态（未填写时主按钮为较暗强调色）、导出必须有HTML；保留已登录的真实文案；作品名称、保存草稿、取消和未保存保护均保留。预览仍允许切换浅色，以检查透明作品在不同底色下的可读性；工作台自身保持黑色。

验证：生产构建通过，核心17项测试通过；内置浏览器1280px检查编辑/项目库/规范/设置/弹窗；保存草稿、未保存保护、载入模板、F2、10球模拟和控制台检查通过。最终Windows exe运行并读取现有Codex登录；1440×1000离屏渲染用于view_image逐项对照布局、黑色层次、字体、控件和预览。此次未更改生成服务，未重新调用AI生成或做真实直播联调。
