Overlay Studio · 直播小游戏工作台

启动
解压完整便携包，双击 Overlay Studio.exe。不要只移动exe，旁边的resources与运行库需要一起保留。
项目、模板预览与导出在本机运行；AI制作可使用本机Codex，也可使用自己配置的模型API。

1.3.1：同步模型与自动填写输出上限
填写Base URL和API Key，点“同步模型列表”，搜索并选择可用模型，无需先填写模型ID或保存配置。
选择模型或重新同步当前模型时，自动采用服务商目录提供的最大输出tokens。DeepSeek读取max_output_tokens，Claude读取max_tokens，兼容服务还支持top_provider.max_completion_tokens。
目录未提供上限时默认8192并明确标注未知；不会把上下文/输入长度当作输出上限，也不会从模型名称猜数值。可手动调低，或点击“按模型重新填写”。目录由服务商提供，账号或路由限制仍以实际响应为准。
工作台支持256至2097152的输出预算，仍保留20MiB响应大小限制。模型目录显示的已知上限更低时，输入框会指出超限原因。
同步只读取模型目录，不发送作品或生成文本；草稿密钥仅用于本次同步，点击保存配置后才保存。修改服务地址或密钥会清除当前目录，防止沿用其他服务的数据。
不支持/models的兼容服务可继续手工填写模型ID；同步失败会在按钮附近给出提示。列表是当前界面的同步结果，重新打开后可再次同步。
1.3.0：引导创作、照片参考与实时编辑
不用先写完整提示词：在“引导创作”说一句想法，模型一次问一个问题；可选答案、自由补充、跳过或让模型决定。
快速模式最多提出3轮关键问题；深入模式持续细化，随时可生成预览。对话、参考资料、需求摘要和编辑过的提示词随项目保存；在“我的项目”重新打开继续。
支持PNG/JPG照片或界面截图（最多4张、每张4MiB、宽高不超过4096），以及UTF-8 TXT/MD提示词（最多4份、每份64KiB、总计128KiB）。可指定配色、布局、角色、功能需求等用途。
上传本身只保存到本机；发送对话或生成时，资料会提交给当前选定模型。图片需要视觉模型。移除参考解除关联并停止发送，原始副本仍留在本地以便恢复。
“需求与提示词”可查看AI整理、参考观察和建议，修改或复制最终提示词。AI建议不会冒充已经确认的用户要求。

生成后进入“实时编辑”：先用可视化参数调速度、尺寸、颜色等，也能切换到HTML源码。修改约300毫秒后更新右侧；可以暂停自动刷新。
重要：刷新会重启当前试玩。实时编辑草稿不会自动覆盖已保存作品；确认后点“保存版本”，旧版留在历史记录。导出前需要保存。
右侧是实际运行的游戏：点击画面或“进入试玩”后可使用游戏定义的键盘、鼠标点击与拖拽操作。“重新开始试玩”重载当前预览。具体操作取决于作品本身实现；工作台不会自动给任意HTML添加控制方式。
旧HTML若没有可视化参数，仍可编辑源码，也可点击让模型添加真正生效的参数。

“检查与审查”包含基础源码/运行检查，以及使用当前模型的AI审查。桌面版可选择附上预览区域截图（需要视觉模型）。审查不改写作品，报告会标记是否有截图，以及源码变更后报告是否过期。
要采用建议，先保存修改，再点击“让模型处理这条”。模型更新作为新版本保存。基础检查和静态截图都不能代替真实互动试玩或直播宿主联调。

1.2.0：其他模型与API Key
进入设置，在“API提供商”选择DeepSeek、OpenRouter、硅基流动、自定义兼容接口或Claude。
填写Base URL、准确的模型ID、最大输出tokens和该服务的API Key，点击“保存配置”。Base URL不包含/chat/completions或/messages。
点击“测试已保存配置”会发送一条简短请求，可能产生少量API用量，不发送项目内容。成功后点击“启用某提供商制作”。
兼容接口使用Chat Completions协议；Claude使用Anthropic原生Messages协议。自定义地址需HTTPS，本机回环HTTP可用。
每个提供商独立保存Key；换模型可保留该服务Key，换主机则须重新填写或清除Key。Key不回显，可在设置中替换或清除。
Windows桌面版使用系统加密存储，配置和密文一起原子保存；不支持加密的开发环境只保留会话密钥，退出后重新填写。
API模式直接生成完整HTML，支持取消和历史版本，不会自主运行工具或浏览器测试。输出截断、错误或取消时保留原版本。
切回Codex：选择“本地Codex”，点击“保存引擎选择”。现有Codex登录和配置不受影响。

制作一个插件
1. 新建作品，填写名称和玩法，选择画布尺寸与视觉风格。
2. 点击“交给 Codex 制作”，等待制作记录完成。可随时取消；取消或失败保留原作品。
3. 在右侧试玩，可切换浅/深底色检查透明效果；这些底色不会写入导出HTML。
4. 修改描述后再制作，旧作品会进入历史版本；也可以保存草稿，稍后继续。
5. 导出插件，选择HTML保存位置，再按直播宿主的方式加载。

已有插件
导入HTML会复制到工作台项目目录，不修改原文件。当前版本面向自包含单HTML；依赖旁边图片、脚本或网络资源的旧插件需要先打包。
“落球演示”直接创建可运行样例；“接金币”“倒计时互动”只是填写玩法的快捷灵感，需要点击制作生成。

Codex
Codex模式检测本机codex.exe与登录状态，不读取或复制Codex密钥，沿用现有模型配置。
找不到时可在设置中选择Codex可执行文件，或清空指定路径重新自动检测。
未登录时在现有Codex客户端完成登录，再回工作台刷新状态。
生成使用独立工作目录与workspace-write权限；不支持的工具、权限或网络需求会在记录中报错，不会自动扩大权限。

预览与直播接入
内置预览隔离执行HTML，默认禁止外部网络、弹窗、文件访问和真实宿主连接。它适合检查离线玩法与透明外观。
需要真实礼物/弹幕协议时，在描述中说明并提供已有接口依据；没有协议时生成模拟入口。
“生成完成”表示Codex成功退出且产生HTML，不等于已通过真实直播宿主、所有浏览器或长时间运行验收。

数据
设置页面可打开本地项目目录。备份整个目录可保留作品、历史版本和制作记录。导出的HTML不包含登录信息或API Key。API密钥密文与Windows账户关联，复制项目目录到另一台机器后通常需要重新填写Key。
当前版本不提供自动更新、云同步和永久删除项目功能。

开发者
源码目录运行 npm install；npm run dev 启动本地开发预览，npm run build 构建，npm start 启动桌面版，npm test 验证服务，npm run package 生成Windows便携目录。
桌面版UI采用React/Vite，Electron使用隔离preload与有限IPC；生成服务通过参数数组调用本机Codex，不拼接用户输入为Shell命令。
