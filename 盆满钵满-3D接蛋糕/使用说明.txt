盆满钵满 · 3D 接蛋糕（透明直播插件原型 V0.1）
====================================================

一、这是什么
------------
透明背景的 3D 直播小游戏。观众送礼物会掉 3D 蛋糕，主播放一只盆在下面接。
没接住的掉到地上，10 分钟内用盆扫回来；超时就消失，并给菘蓝整蛊机的「加班机」自动加时间。

单文件、离线运行、无需联网：盆满钵满-3D接蛋糕-V0.1.html（约 3.14 MB，Three.js 与 13 个 CC0 烘焙模型已内置）。

3D 素材默认使用 Tiny Treats – Baked Goods（作者 Isa Lousberg，CC0 1.0，个人/商业均可）。
想换回早期「程序化糖果风」：S 打开设置 → 素材 → 3D 素材风格 → 程序化糖果（切换后自动重载）。

画面带完整光影效果：主光投影、地面接触阴影、粉色轮廓光、盆内暖光、地面光池和星芒闪光。
如果宿主/电脑帧率偏低，启动约 2.6 秒后会自动降低光影质量保住流畅度；
想强制高画质可在 OBS 浏览器源地址后加 ?quality=high（展示/截图用）。


二、怎么导入
------------
【菘蓝整蛊机】
1. 打开菘蓝整蛊机的「自定义插件」/插件管理，导入 HTML：盆满钵满-3D接蛋糕-V0.1.html
2. 打开插件后即为透明输出；用 OBS 浏览器源捕获（或宿主自带的窗口/场景）。

【白曜重工】
1. 插件库 → 导入 HTML，选这个文件。
2. 默认关闭，需要在「主播与规则」里启用并设为动作目标。
3. 白曜里用「规则 → 动作」触发；动作名支持：掉蛋糕 / dropCakes / cakeDrop / addCakes
   （动作数值 value = 掉落件数，1~200）。礼物原始事件也会走旧版 SonglanPlugin.onGift。

【OBS 浏览器源 / 本地预览】
直接双击打开 HTML 也能玩（会自动进入演示模式，随机掉蛋糕）。
加 ?preview=1 会有棋盘格底色，方便看透明边界；正式上屏不要加。


三、操作
--------
- 鼠标 / 手指：移动盆（左右 = 横向，上下 = 前后）
- 键盘：A/D 或 ←/→ 左右，W/S 或 ↑/↓ 前后
- P：暂停 / 继续
- S：设置面板（完成并应用会保存到本地）
- F2：演示控制台（模拟送礼、立刻过期、清空地面）
- 空格：演示模式下模拟送 1 个玫瑰

设置面板里可以调：
- 盆的大小 / 蛋糕大小 / 下落速度
- 地上停留分钟数（默认 10 分钟）、超时消失每件加多少秒（默认 30 秒）
- 是否联动菘蓝加班机
- 上传观众素材（图片，最多 8 张，自动压缩到 512px；掉落时会按比例混入，做成「照片饼干」）
- 3D 素材风格（CC0 精修 / 程序化糖果，切换后自动重载）
- 礼物 → 掉落数量表（默认：小心心 1、玫瑰 5、棒棒糖 3、嘉年华 60、火箭 60；未配置的礼物默认 3 件）
- 阴影 / 音效 / HUD 显隐 / 预览底色


四、礼物与加班机怎么接
----------------------
1. 礼物规则：设置面板里「礼物 → 掉落数量」按礼物名配置；观众连击数量会相乘
   （例：玫瑰 ×5，规则 5 → 掉 25 件），单次上限 200 件。
2. 加班机（仅菘蓝整蛊机）：
   - 本插件通过 WebSocket 连接「HTTP 端口 + 827」（菘蓝加班机的固定端口），
     连接后先发 {action:'identify', module:'自定义插件'}。
   - 每件超时消失发送 {action:'overtime-manual', delta: 30}，让加班机加 30 秒。
   - 请在菘蓝加班机里把「初始时间 / 是否允许负数」按需要设置。
   - 注意：这是原型方案，真实宿主是否允许插件页面直发该消息尚未实测（见验收记录）。
     HUD 里的「加班秒数」始终会统计；连接是否成功看设置面板「连接」一栏。
3. 白曜重工目前没有加班机模块，超时只显示特效并统计秒数（不会加到其它系统）。


五、内容上限（防止直播卡顿）
----------------------------
- 同屏下落物 64、地面 48、盆内展示 56、待生成队列 420（超出会提示，不静默丢弃已接住内容）。
- 观众上传素材同屏最多 10 件，超出自动回退成普通蛋糕。
- 地面物品超过 6 件时，倒计时数字只在最后 2 分钟显示，避免糊屏（圆环颜色会随时间变黄/变红）。


六、已知边界
------------
- 已在 headless Chrome（软件渲染）跑过完整玩法和假宿主联调；真实菘蓝/白曜/OBS CEF、真实直播间礼物、
  加班机真实加时均未实测。
- 真实 GPU 帧率未测：验收环境软件渲染约 9–12.5 FPS（CC0 素材比程序化更省），真实显卡应远高于此。
- CC0 素材包没有冰淇淋/马卡龙，这两类仍用早期程序化素材（风格接近）；如需完全统一可再找 CC0 补包。
- 上传素材保存在本地 localStorage，不联网、不跨设备同步；清理浏览器数据会丢失。
- 加班机端口按「当前页面 HTTP 端口 + 827」计算；在菘蓝 iframe.srcdoc 中会尝试读取父页面端口，
  非默认端口场景建议实测一次。
