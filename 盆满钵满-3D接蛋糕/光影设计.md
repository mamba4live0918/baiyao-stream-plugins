# 光影设计（V0.1 起为硬性要求）

用户明确要求：**这个插件必须做光影效果**。本文件记录当前实现、调参入口和后续迭代的验收清单，防止以后改场景时把光影改没。

## 目标

透明直播层没有背景，光影是唯一能把「3D 物体」和「平贴图」区分开的东西。目标是：
1. 主体（盆/蛋糕）有明确的受光面、暗面和边缘高光；
2. 有能落在地面/接触面上的**可见阴影**，并能锚定物体位置；
3. 透明背景上没有整块底色，但要有舞台灯般的氛围光（光池/背光/闪光）；
4. 弱 GPU / OBS CEF 上可自动降档，优先保住帧率。

## 当前实现（src/game.js）

### 环境反射（IBL）
- 程序化生成 1024×512 equirect 环境贴图（暖色柔光箱 + 右侧粉色轮廓 + 左侧冷色补光 + 底部地面暖反射），
  经 `PMREMGenerator.fromEquirectangular()` 转成 `scene.environment`。
- `scene.environmentIntensity = 0.5`（暂停时随整体压暗）。
- 材质侧：糖霜/釉面类（flatten 时归为 glossy）用 `MeshPhysicalMaterial` + `clearcoat:1 / clearcoatRoughness:0.16`，
  `envMapIntensity ≈ 1.25`；金属（金币）`envMapIntensity 1.5`；陶瓷盆 `envMapIntensity 1.5` 且 roughness×0.78。
- 效果：冰激凌球、马卡龙、奶油、盆口釉面有清晰高光与反射；金币有金属反射。

### 主光与投影
- `DirectionalLight` 主光 3.1，色温偏暖 `0xfff4e6`，位置 `(3.2, 19, 7.5)`，目标 `(0,0,1)`。
- `renderer.shadowMap`：`PCFShadowMap`，mapSize **2048**，shadow.radius 4（软边），ortho 范围收紧到主要活动区 `[-9.5,9.5]×[-8,13]`。
- 地面：`ShadowMaterial(opacity 0.30)` 透明接收面 —— 只有阴影、没有底色，适合透明直播层。
- 所有下落物/盆 `castShadow = true`；地面物件另有共享材质的**接触阴影**（径向渐变平面，opacity 0.36），
  让物体在透明背景下也“压”在地面上；盆下另有一块更大的柔和阴影 blob。
- CC0 外部模型（Tiny Treats）加载后同样强制 `castShadow = true`，材质 `envMapIntensity = 0.85`，
  贴图按 sRGB 采样，保证接入外部素材后光影方案不塌。

### 舞台光
- 粉色轮廓聚光 `SpotLight(0xff86b8, 240)` 从左后方打轮廓；
- 暖色聚光 `SpotLight(0xffd9a6, 160)` 从右前上方补暖色；
- 盆内暖光 `PointLight(0xffc079, 7)` 跟随盆，让盆里的蛋糕从内部发光；
- 地面暖色光池（加法混合的径向渐变平面，opacity 0.5）模拟舞台地光；
- 物体后方的大尺寸柔和背光 Sprite（加法混合，opacity 0.22）增加纵深；
- 常驻小星芒闪光（Sprite 池，≤10 个）在盆内/地面物体上随机明灭，接住/超时另有粒子爆发。

### 暂停与画质
- 暂停时不关灯，而是整体乘 `pausedFade`（0.5），保留光影层次。
- 画质自动降档：启动后 2.6 秒测帧率，`< 24fps` 自动 `view.setQuality('low')`：
  - shadow map 2048 → 1024（释放旧 shadow map 重建）
  - 关闭暖色聚光与常驻闪光
  - `environmentIntensity` 0.5 → 0.42
  - renderer DPR 上限 1.75 → 1.0
  - URL 加 `?quality=high` 可强制高画质（验收/截图用），`?quality=low` 强制低画质。

## 调参入口

- 运行时：`CakeCatch.view.setLightBase({ hemi, key, fill, rim, pink, warm, glow, env })`
- 画质：`CakeCatch.view.setQuality('low' | 'high')`
- 灯光对象：`CakeCatch.view.lights`（hemi/keyLight/fillLight/rimLight/pinkSpot/warmSpot/bowlGlow/envRT）

## 验收清点（每次改 3D 场景都要过）

1. 透明模式下截图，盆与地面物件下方有**看得见**的阴影（不是只有环境光变暗）。
2. 关闭阴影开关（设置面板）后，接触阴影仍在、光照层次不崩。
3. 盆内蛋糕有高光/暗面，冰激凌/糖霜类不是纯平色块。
4. 暂停时整体变暗但光影方向仍可辨。
5. `?quality=low` 下仍保留主光/阴影/轮廓色，不是全灭。
6. 软件渲染（SwiftShader）下自动降档生效；真实 GPU 上不被误降档。
7. 截图证据：`docs/shots/final-07-lighting-closeup.png`、`final-08-on-stream-closeup.png`、`final-04-on-stream.png`。

## 当前已知限制

- 真实 GPU / OBS CEF 帧率未测；软件渲染下高画质约 4–5 FPS（参考值），低画质约 17 FPS。
- 阴影只来自一盏主光；没有实时全局光照、SSAO、Bloom 等后处理（单文件未引入 composer）。
- 光池/背光是美术近似，不是物理光源；在极端亮/暗的直播画面上可能需要再调 opacity。
