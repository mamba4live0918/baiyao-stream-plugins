# 第 1 批素材 · 共用生成规范

此文件记录画风、文件对应关系和后处理边界。每次实际调用的完整 prompt 与生成原图路径记录在 `generation-records.json`，生成器不得把下列文本视为已完成调用的证明。

所有图片必须由图像生成工具创作，使用透明背景。扁平 2D Q 版卡通，深棕墨线 `#49372d`，平涂、一层阴影、少量白色高光；光从左上来。按短边 1080 的建议显示尺寸观察时，墨线约 3–4 像素。没有字母、数字、汉字、logo、品牌、二维码或货币符号。需要代码写字的位置保留干净空白。

顾客为正面、略朝中间看的半身像，头到胸口。16 个角色的发型、服装、肤色和年龄感有明显区别。每个角色的 `happy / neutral / impatient / angry` 四张图必须同画布、同构图、同位置、同大小，只改面部；生气状态脸红且张嘴。每张固定透明画布 220×260，显示 110×130。不得通过代码绘图、换色或拼接五官制作表情。

柜台为四种店型的台面与正面板：`noodle` 番茄红、`pancake` 蛋黄色、`tea` 薄荷色、`sushi` 原木台面与藏青正面板。左片 256×420，中片 512×420，右片 256×420。三个片段共享台面高度、透视、描边、前面板色与阴影。中片左右必须无缝横向平铺，内部的直线纹理与台面线在边缘连续；两侧片段与中片也必须连续。圆形空白店招另外出图 240×240。

用户最新审阅：64 张顾客与全部 13 张小道具已经认可，禁止重做或覆盖原图。第一版四家柜台过于像纯色按钮，已拒绝。本轮只重绘柜台与店招：必须像真实摊位，有厚实、略旧的木台面、木纹和上方高光，以及各店布帘或装饰纹样。仍由图像工具生成，不能程序画纹理、换色或用单列拉伸抹去图案。新母图与店招使用 `raw/counters-v2/`，实际调用另存 `prompts/counters-v2-*.json`。中片由有意义的 256 像素原画条带和水平镜像组成，保留木纹与店面花纹；具体裁切矩形和镜像关系写入 manifest。后处理只做裁切、镜像、缩放、原画像素拼接和格式转换。

钱罐与铜钱顶层均使用 280×300 透明画布，同坐标叠合；罐口位置完全一致。罐子上留空白标签。铜钱顶层只包含露出罐口的铜钱，不重复画罐身。铜钱为卡通圆形方孔钱，没有货币符号。

灭火器、垃圾桶、胸牌、气泡和三种印章框按 manifest 的画布生成。印章框是略有印泥质感的双线圆角框，内部留透明空白。所有素材的边缘必须干净，不能夹带白色或灰色底。

目录规则：源 PNG 为 `src/<group>/<id>.png`，WebP 为 `webp/<group>/<id>.webp`。后处理仅可规范画布大小、保持比例留透明边、裁切经过人工审核的图集分格、转换 PNG/WebP；不能通过代码替代创作、改画风或改色来凑合。
