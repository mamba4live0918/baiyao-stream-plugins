V1.6 · 送礼物就来顾客
先模拟点单（设置②里的 ▶ 可试送点单礼物），在设置里选店，照下面做菜、端给顾客，也可试捣乱/帮忙。

🍜 点面箱 → 等绿圈 → 锅拖碗，一下1两 → 碗拖给顾客。
🍣 点鱼箱 → 按刀向下划 → 鱼片拖盘，一下1片 → 盘拖给顾客。
🫓 点面糊桶 → 在鏊子上画圈摊开 → 点蛋篮，一下1蛋 → 等绿圈，铲子拖饼装袋，袋拖给顾客。
🧋 点珍珠罐，一下1勺下进小锅 → 等绿圈，小锅拖到杯里，一下1勺 → 按住雪克杯左右摇，拖到杯里封口 → 茶杯拖给顾客。
灭火器拖火上；小偷敲3下；电闸向上推；猫拎出摊位；糊脸按住来回擦。
画面上的牌子（计时牌、门外人数、通缉令、统计牌）按住能拖，鼠标移上去拖右下角圆点改大小。
