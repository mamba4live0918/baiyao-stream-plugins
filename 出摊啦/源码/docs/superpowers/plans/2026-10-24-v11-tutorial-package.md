# 出摊啦 V1.1 详细教程与交付包

> 执行方式：当前会话并行制作独立片段，主代理合片、核验并打包。

**目标：** 交付带可见鼠标和中文说明的详细教程，从宿主导入、OBS网址，到设置、四店操作、捣乱救场、交租。

**制作：** 复用现有本地 Playwright 录像与 FFmpeg，不更改已验收运行源码。白曜使用原版界面和隔离内存数据演示导入；OBS只说明操作步骤；所有游戏操作与设置在独立离线上下文录制。画面标明离线模拟，礼物回放不冒充真实送礼。

**技术：** 1920×1080、30fps、H.264/yuv420p，中文字幕；PDF嵌入中文字体并逐页检查。
