# 出摊啦 · V1.6

发布包内的「出摊啦-1.html」是透明单文件。本地文件可离线试玩；直播收弹幕和礼物，需要先导入白曜重工或菘蓝并启用模块，再把OBS浏览器来源换成宿主给的网址。使用“交互”操作，按S打开设置、框脸并填写礼物表。短图文见包内6页使用说明.pdf，演示见出摊啦演示.mp4。开发目录仍可直接打开「试玩.html」体验。

直播接入：白曜重工中导入单文件「出摊啦-1.html」→启用模块→复制白曜给的网址→把OBS浏览器来源改用该网址（取消“本地文件”）。菘蓝同理。来源宽高与直播画布一致，放在皮套来源上方。只在OBS中选择本地HTML，收不到宿主的礼物和弹幕。

观众默认可发「点单 / 来一份 / 来一碗 / 来一杯 / 来一盘」，也可用当前店词：面馆「来碗面 / 吃面 / 一碗面 / 来份面」、煎饼摊「煎饼」、奶茶店「奶茶」、日料店「生鱼片 / 刺身」。默认每人同时1单，再发一次就是催单；这些设置可改。

白曜规则动作ID：

| ID | 动作 |
|---|---|
| order | 点单 |
| fire | 放火 |
| thief | 小偷 |
| blackout | 停电 |
| cat | 野猫 |
| tour | 旅行团 |
| boom | 爆锅糊脸 |
| spice | 乱加料 |
| helper | 帮手 |
| guard | 保安 |
| overtime | 加班，单位为分钟（V1.6 起按设置③「加班记到」：白曜加班机或插件自带的加班机） |

先点「模拟点单」，看顾客泡泡里的数量，再按下面四步做：

- 面馆：点面饼箱，一下下一两 → 等锅变绿圈 → 从锅拖到碗里，一下捞一两 → 把碗拖给顾客。默认煮4秒、绿圈6秒；继续下面重新煮整锅。过绿圈先冒烟3秒，可点锅倒掉；再不管就起火，8秒后烧坏，需拖灭火器来清理后重做。
- 日料店：点鱼箱上一块鱼 → 按住刀向下划，一刀一片 → 鱼片拖到盘里，一下装一片 → 把盘拖给顾客。默认一块鱼切 8 片，能提前备货。切斜了会碎，仍算一片，顾客会说「凑合」。
- 煎饼摊：点面糊桶下糊 → 按住鏊子大概画个圈摊开 → 点蛋篮，一下一个蛋 → 最后一个蛋后等4秒绿圈，把铲子拖到饼上或袋口，自动卷饼装袋，再把袋子拖给顾客。画圈不用闭合，明显转弯就行；点击或只画直线不算。过绿圈先冒烟，可点鏊子倒掉；继续不管会起火，需要灭火器。
- 奶茶店：点珍珠罐，一下加一勺 → 按住雪克杯左右摇一下 → 把雪克杯拖到茶杯，自动倒茶封口 → 把茶杯拖给顾客。左右来回不用很准，纯竖着拖不算。杯里奶茶不会自然煮糊；放火烧的是旁边煮珍珠的小锅，已封口的奶茶不会被追溯烧坏。

碗、盘、袋、杯上显示当前数量。把成品拖到哪位顾客身上就给谁，工具范围不挡端菜；拖得很短当没拖，拖到空处不消耗菜。只有垃圾桶是丢弃落点，点击垃圾桶则有成品先倒成品，否则清理未做完的食材。松手端出后先显示「要 4 · 给 3」，随后自动盖章、加减铜板、顾客离场并补位。被猫吃到0个蛋/0勺珍珠的袋和杯仍是成品，仍能端出，按少给结算；没装袋的饼和没倒茶封口的杯不能端。

每单底价统一 15 铜板，数量差一份加减 3：要 4 片时，给 4 片 +15，给 5 片 +12，给 3 片未被发现 +18；被发现这单不收，再罚 10。少 1/2/3 份以上的发现概率为 15%/40%/70%。不耐烦只折底价八折，生气底价半价 7.5，差额照算；烧焦/乱加料计分默认 0。

- 直播页移动鼠标后显示名牌、开店/设置和四步提示；停止移动 2.5 秒或鼠标离开页面后淡出。柜台上的操作句只在鼠标移上来时显示，数量一直显示。点单计数牌仅在试玩页出现，桌面工具、钱罐、交租牌和加班机是游戏内容。
- 右上角「设置」或键盘 S 打开设置；改动自动保存，Esc 关闭。四个按钮选店，下面可改当前店的最少～最多数量；填成一样就是固定数量，都填 1 就不用数。默认面 1～3、鱼 3～5、蛋 1～2、珍珠 1～3。切店保留顾客，按新店范围重新抽需求。
- 高级设置可改底价、差价、发现概率、罚款、坏菜收入、心情折扣、火候、锅容量与每块鱼片数；锅容量 0 = 不限。「清零铜板和出餐统计」保留交租进度、已加班和待同步记录。
- 「框出我的脸」调整保护区，预设可重新放置。默认脸框随画面比例适配，手动修改后保存百分比。
- 点「模拟点单」或「一键来 50 人」让顾客进场，连续点十次可看 500 人。顾客从柜台往上越站越小，避开脸框；站满后缩到 85%，再多就显示「门外还有 N 人」。
- 顾客等待 30 / 60 / 120 秒依次变为平淡、不耐烦、生气；生气会冒烟、间歇跺脚，超过一半生气会齐喊「快点！快点！」。同一观众重复点单会催单，小人跳起喊「快点！」，不新增顾客。
- 胸牌在前排和入场 3 秒内显示，点单泡泡只给前排。可在设置中关闭名字、关闭挤一挤或调整心情时间。
- 人群带入场固定的小错位，补位不重抽；未满排从中间向两侧站。
- 试玩页的「模拟送走前5位」只看补位，不加铜板。「快进到交租」推进当前营业剩余时间并执行本地收租。捣乱和帮忙按钮直接触发玩法。
- 礼物只按设置表匹配；表外礼物不触发。真实 SDK 适配和离线模拟不等于真实直播已联调。
- 设置存 chutan.v1.settings，铜板/出餐统计、当前场次的交租与加班流水存 chutan.v1.stats。顾客、捣乱、通缉和厨房只在内存，刷新清空；统计与尚未结束的场次账本保留。
- 页面隐藏时暂停人群、厨房和交租，重新显示后继续。刷新后先关闭营业，离线期间不计费。
- V1.6 起加班按设置③「加班记到」记账（默认「自动」）：在白曜里、或填了连接码 → 白曜加班机（白曜重工 0.27.0 以上；不在白曜里连白曜本机连接 `ws://127.0.0.1:47833/overtime`，要填白曜给的连接码）；都不是 → 插件自带的加班机。「测试连接」只连一下、打个招呼，不改时间。不启动或操控 OBS。

交租从第一个顾客进店开始，每营业10分钟收100铜板；按「打烊」暂停，同一场重新开店接着剩余时间走。店里持续无排队顾客满一个交租周期，结清本期后自动打烊。最后30秒交租牌变红晃动。够数扣租金；不够交完正余额，默认差10铜板加班1分钟，秒数向上取整。已有负余额保留，不扩大本次缺额。

打烊、关闭页面或电脑睡眠满1小时，这一场结束：交租进度和本场全部加班流水（包括还没送到白曜的）清零，铜板和出餐统计保留。牌子回到「等首位顾客」，下一位从默认10分钟交租开始。旧顾客、厨房和临时效果同时清理。营业中页面卡6秒、睡40分钟等不足1小时的空档，只跳过空档时间，顾客和营业状态保留，随后正常走表，不会醒来批收租；调试快进仍按显式时长走。

设置③「开新的一场」重置本场，铜板不动；与高级设置里的「清零铜板和出餐统计」是两个独立操作。第一次点击变成「确定……？」，3秒内再点一次才执行；超时、关闭设置或重绘设置会取消确认，两按钮不会互相确认。

捣乱与救场：

- 放火：把左侧灭火器拖到火上。火会逐渐变大，烧坏后灶不能用，灭火清理后再做。
- 小偷：混进人群，连续点3下敲晕；默认6秒后摸到钱罐，卷走正余额30%。逃走会留下通缉令，保安到场追回一名通缉者的铜板。
- 停电：手电跟着鼠标，脸只暗一半；把右侧电闸往上推恢复。默认20秒自动来电。
- 野猫：每4秒偷1份，先吃成品再吃备货。抓住猫，拖到摊位外松手赶走；拎着时不会偷吃。在途菜不会被改数量。
- 旅行团：大巴默认带10人，胸牌标团名；多次旅行团依次到场，大团分帧进队，放不下仍在门外等。
- 爆锅糊脸：面条/面糊/奶茶渍，日料店是整鱼；按住鼠标在脸上来回擦干净。短抖动可在高级设置关闭。
- 乱加料：大手往成品倒辣椒或芥末，端出去默认0铜板并盖黑暗料理章；拖垃圾桶倒掉重做。没成品时先显示「XX · 盯上了下一份菜！」，排队等下一份。帮手救场的横幅显示帮手名字。

帮手每一件先处理着火→小偷→停电→猫→坏菜→擦脸；无麻烦则按顾客所需数量上菜，收完整底价。没有可做的事会保留次数，新客到来继续工作。在途的菜不会被帮手追溯修改或重复结算。保安先追回一个通缉记录，再按N次挡住后续捣乱，也能挡旅行团。

设置中为捣乱礼物填随机N～M、帮忙礼物填「派谁+N～M」，▶可直接试规则。表外礼物不触发。多次效果按数量排队，不用隐藏上限吞掉。高级设置可改烟火、偷钱、停电、猫间隔、旅行团人数、帮手速度、横幅和通缉令。短音效由WebAudio合成，先在画面点一下解锁，也可关音效。

包租婆收租后离开；不足时盖章并显示「差多少 → 加班多久」，第二行写「加到加班机」，没连上时写「先记下，连上加班机再加」。记到插件自带的加班机时，交租牌下面挂「距离下播 / 已加班」（跟着交租牌拖动、缩放，可在设置③关掉）；记到白曜时剩余时间看白曜加班机。设置可改交租开关、间隔、铜板和加班换算。改间隔保留本轮交租点，下轮用新间隔。

加班机：V1.6 起两种——白曜加班机，或插件自带的加班机（V1.5 只有白曜的；咩播 V1.5 起去掉）。设置③「加班记到」：自动（默认：在白曜里或填了连接码 → 白曜，不然 → 自带）/ 插件自带的加班机 / 白曜加班机。
- 交租差额和白曜 overtime 动作（以分钟记）都先记进本场账本：记到白曜的送到后标记已送；记到自带的直接加到倒计时（账本里记成 local，不送）。
- 没连上先攒着，连上自动补发，每笔只送一次。
- V1.3/V1.4 存档里的旧流水按已处理算，不会补发。
- 礼物加减时间：记到白曜时在白曜加班机的礼物列表里设；记到自带的时在设置③「礼物加减时间」设（礼物名 → 加时 / 减时 → 最少～最多分钟，送几个算几次；只在记到自带的时生效，和点单 / 捣乱 / 帮忙表互不影响）。V1.3/V1.4 的旧加班礼物表还留在 chutan.v1_3.extras，不用。
- 自带加班机：预设时长、开始 / 暂停、重置（点两下）、手动加减、画面上显示倒计时。存在 chutan.v1_6.local-overtime（「加班记到」存在 chutan.v1_6.overtime），按真实时间走，刷新、关页接着走；「开新的一场」会把它重置，打烊或离线满 1 小时结束本场不会。

不在白曜里时（菘蓝里、直接放进 OBS，包括勾了「本地文件」的浏览器来源），设置③填白曜「加班机 → 加班设置 → 插件连接」里的连接码（不分大小写，横线可有可无），再点「连接」才用上；「测试连接」只试不存。白曜明细里显示「出摊啦（外部）」。没填连接码只能看时间，不会加。连接断在半路、不知道有没有加上的那一笔按已送算，宁可少加也不加两遍。

素材预览入口：`源码/assets/预览.html`。顾客、四店柜台、通用小件、22张面馆/日料工具、5张交租/加班、45张捣乱/帮忙和20张煎饼/奶茶工具共185张。可切棋盘/皮套、PNG/WebP，查看各分层组合，也可「随机摆200个人」。整份HTML上限10MB，素材画质优先。

柜台区同时展示每家店的 1920 和 2560 宽拼接，可选择适合视口或实际像素查看。正式直播页已使用新版柜台，台面居中且最宽为短边的 2.2 倍，店招文字由代码绘制。

默认点单口令为「点单、来一份、来一碗、来一杯、来一盘」。面馆店铺词为「来碗面、吃面、一碗面、来份面」；其他店为「煎饼」「奶茶」「生鱼片、刺身」。「见面了」「外面好冷」「来个人」不会按默认规则点单；自定义口令可在设置中修改。

开发：在「源码」中运行 `npm test`、`npm run build`、`npm run qa`。构建默认压缩脚本并保留图片内联；素材已导出，批准素材受哈希校验保护；生成提示词、来源和选图记录在 `源码/assets/prompts/`。构建复用同工作区「拼豆」已安装的 esbuild，素材处理复用已有 sharp，浏览器验收复用 playwright-core 和本机 Chrome。产物运行不需要这些依赖。
