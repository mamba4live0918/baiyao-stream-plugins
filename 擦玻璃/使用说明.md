# 擦玻璃 · 使用说明（V1.8 · 2026-10-24）

整块屏幕是一面玻璃，皮套在玻璃后面。观众送礼物，往玻璃上砸鸡蛋、泼奶茶、甩泥巴、贴小广告、哈气写字，还会放猫、小鸟、壁虎来捣乱；你还能上传自己的图片做成异形贴纸，让观众往玻璃上贴（见下面「我的贴纸」）。你用鼠标拿刮水器刮干净。观众也能送擦窗机器人、贴保护膜来帮你。

没有关卡，一直擦就行。你自己框住脸（多边形，怎么框都行）：框外面可以被糊满，小广告和脏东西一张张紧贴着框的边，自然围出一个只露脸的空隙，就像主播被一堆东西淹没、只露出一张脸。

## 放进 OBS / 白曜

1. 新建「浏览器」来源，勾选「本地文件」，选 `擦玻璃.html`（或分享包里的 `擦玻璃-1.html`），宽、高和画布一样大：横屏 1920×1080、竖屏 1080×1920、带鱼屏、别的分辨率都行（见下面「横屏、竖屏都能用」）。
2. 在来源上右键选「交互」，在交互窗口里用鼠标玩。鼠标在玻璃上是一个**白圈（中间一个粉点）**，一直看得见；这是你自己的光标，直播画面里没有它，观众只看得到你手里的刮水器。
3. 第一次用先框好脸：按 S 打开设置 →「④ 你的脸」→「在画面上框住我的脸」，拖圆点把框贴到皮套的脸上（怎么拖见下面），点「完成」。
4. 白曜重工：导入单文件（`擦玻璃-1.html`）→ 启用模块 → 把 OBS 来源换成白曜给的网址；规则动作 id 见下面「直播接入」。

### 横屏、竖屏都能用

- **东西的大小按画面短边算**：横屏的短边是高，竖屏的短边是宽。所以 1920×1080 横屏和 1080×1920 竖屏上，鸡蛋、小广告、猫、刮水器一样大；换成 1280×720、2560×1440 也按比例缩放。
- **默认露脸框按画面比例生成，不会被拉变形**：假设半身皮套站在画面底部——横屏时脸在中上部，竖屏时皮套撑满宽度站在下面，脸大约在画面中间。「只露脸 / 露到肩 / 露半身」三个预设也按比例生成。
- 还没动过的默认框，换了画面比例会自动重新摆；**自己框过、点过预设的不会动**。换了画面比例（比如从横屏改成竖屏），记得重新框一下脸。
- 窄窗口里，设置面板、框脸按钮栏、试玩台顶栏都会自动换行或横着滑，不会跑出画面。

## 设置（按 S 打开，只有一页）

鼠标在画面上动一下，右上角出现齿轮，点它（或按 S）。改了马上生效、自动保存；Esc 或点面板外面就关上。

最上面「**接收直播间的礼物**」默认开着，装上就能用。

**① 捣乱池**——九样捣乱（鸡蛋、奶茶、泥巴、小广告、**我的贴纸**、哈气、猫、鸟、壁虎），勾上的才会来。观众送捣乱礼物，就从勾上的里面随机挑。至少留一样。出厂勾上的是八样，「我的贴纸」要先上传了图片才能勾。

**我的贴纸**（就在捣乱池下面）：

- 点「**＋ 上传我的贴纸**」选图片，一次可以选好几张。**透明底的 PNG / WebP 最好**：插件会裁掉四周透明的边，按图案的轮廓剪成**异形贴纸**，自动加一圈白边（像真的刀模贴纸）。JPG 没有透明底，就是一张带白边的长方形贴纸；GIF 动图只取第一张。图太大会自动缩小（最长边 512 像素），不用自己处理。
- 第一次上传会**自动勾上**「我的贴纸」；之后观众送捣乱礼物，随机到它就从你的贴纸里轮着贴一张上来，右下角一个小白签写「@送礼的观众」。
- 缩略图右上角的 ✕ = 删掉这张；全删了会自动取消勾选。「我的贴纸」随时能自己取消勾选，之后再上传也不会自己勾回去。
- 勾着「我的贴纸」、可这里一张贴纸都没有（比如换了电脑、清了浏览器数据）：轮到它时先照常贴小广告，面板里会用黄字提示。
- **上传一次一直在**：贴纸存在这个浏览器里，关掉 OBS、刷新都还在。OBS 和白曜是两个不同的浏览器，**各自要上传一次**（见下面「存档」）。万一浏览器不让存，会提示「这次直播里能用，关掉以后要重新上传」。
- **自己上传的图要自己保证合规**：别放二维码、联系方式、品牌、低俗的东西（插件认不出图片里写了什么）。

**② 捣乱礼物**——一行一个礼物，写上「来几下」的范围：

| 礼物名 | 来几下（随机） |
|---|---|
| 玫瑰 | 1 ～ 1 下 |
| 大厨煎蛋 | 3 ～ 5 下 |
| 猫咪来袭 | 4 ～ 6 下 |

- 观众送一个，就从捣乱池里随机来几下，每次在两个数之间随机（3 ～ 5 下 = 这次可能来 3 下、4 下或者 5 下）。**送几个就来几轮**。
- **一下 = 随机一样捣乱**：鸡蛋 2 个、奶茶 1 杯、泥巴 3 团、小广告 2 张、我的贴纸 1 张、一团哈气、一只猫 / 鸟 / 壁虎。
- 礼物名照着抖音里的写，多打了空格、表情没关系。
- 每行后面的 ▶ =「假装有人送了一个」，马上看效果；✕ = 删掉这一行；「＋ 添加一个捣乱礼物」= 加一行，直接打礼物名。
- **两张表里都没有的礼物，送了不会有反应**——想让哪个礼物有用，就把它加进表里。
- 默认的表：小心心 / 玫瑰 / 人气票 / 抖音 各 1 下；番茄、棒棒糖 1 ～ 2 下；亲吻、口红示爱、做我的猫 2 ～ 3 下；墨汁炸弹 2 ～ 4 下；大厨煎蛋、灵动小鸟 3 ～ 5 下；猫咪来袭 4 ～ 6 下。抖音礼物经常上新下架，以直播伴侣里能送的为准。

**③ 保护礼物**——一行一个礼物，选「擦窗机器人」或「保护膜」：

| 礼物名 | 干什么 | 来多少（随机） |
|---|---|---|
| 机器人工坊 | 擦窗机器人 | 1 ～ 1 台 |
| 为你撑伞 | 保护膜 | 挡 10 ～ 20 下 |

- **擦窗机器人**：来几台，自己找脏的地方擦。
- **保护膜**：能挡几下。贴着的时候砸来的东西都落在膜上，每挡一下耐久少一点、膜上的裂纹多一点；**挡满了自己裂开、连同上面的脏东西一起掉下去**。膜还在的时候再有人送，就是加耐久。
- 两张表里的礼物名不能重。

**④ 你的脸**：「在画面上框住我的脸」，或者一键「只露脸 / 露到肩 / 露半身」（头顶位置不动）。框住的地方永远不会被挡住。框是**多边形**，在画面上：

- **拖圆点** = 改形状；
- 点**两个圆点中间的小点** = 在那里加一个点（按住还能接着拖）；
- **右键（或双击）圆点** = 删掉这个点（至少留 3 个，最多 24 个）；
- **按住框里面拖** = 整个挪；
- 「**重新画**」= 沿着脸（连耳朵、头发、肩膀都行）一圈点下去，点回第一个点（或双击、回车）就画好了，Esc 取消。

**⑤ 声音**：音效开关和音量。

下面三个按钮：清空玻璃、打开试玩面板、恢复默认设置。

**高级设置（不懂就别动）**，默认收起：东西大小、淹没感、自己落灰、刮条宽度；露脸区开关和边缘羽化；画面上的字（观众名字、计数、榜单、操作提示）、玻璃反光、砸中时抖不抖；上限；统计和清零。

## 怎么玩（只用鼠标左键）

- 东西砸上来时整块玻璃会震一下、出一圈震波，落点蹦出拟声字（「啪叽！」「哗啦！」「咔嚓！」「噗！」）。
- **按住拖动 = 刮玻璃**。刮条会自己转到和拖的方向垂直；刮过的地方边缘利落，两头留细水线、挂水珠。
- 每擦掉一块"叮"一声，左下角出「擦掉了 @小明 的鸡蛋」；连着擦，叮的音调一级级升高。右上角计「今天擦掉 N 处」。
- 硬的东西（鸡蛋、蛋黄、泥巴、奶茶、鸟屎、胶印、碎纸）第一遍会被抹开、留刮痕，**回头再刮一遍**就干净了（同一个方向刮过去算一遍，掉头算第二遍）。
- **鸡蛋**：飞来之前落点先出一个带名字的红色准星，**手快点中就能接住**扔回去（「白曜接住了 @A 的鸡蛋，回敬！」）。
- **小广告**：每张都有一个"贴的方向"——贴的时候是从一头往另一头抹平的，抹到最后的那个角（或那条边）会**翘起来**；浆糊贴的还看得到顺着这个方向的刷痕，胶带贴的胶带在对面那头。
  - **从翘起来的地方开始，顺着贴的方向往回揭**（偏差 40° 以内）：纸一路卷起来，揭到七成整张掉下来，干干净净（「完整撕下 @A 的小广告！」）。浆糊贴的会留一两小块浆糊印，胶带贴的留胶印，刮一下就没了。
  - **方向不对**（横着拽、往外拽）："嘶啦"一声撕烂，揭起来的那截被扯走，剩下半张还粘着，毛边那头翘起来，可以接着顺着撕。撕烂两三次、剩得太小，就变成**碎纸**粘在玻璃上，只能刮掉。
  - 鼠标停在纸上，翘起来的地方会出现**白色箭头**，指着该往哪边揭。
  - **小广告一直能贴，不限张数，而且每一张都得撕**，刮不掉。一层层叠着贴，上面那张揭开，就露出底下那张，接着撕。
  - **我的贴纸**和不干胶小广告一样撕：图案靠边的地方翘着（鼠标停上去出箭头），顺着往回揭整张掉，揭歪了撕烂。贴纸是异形的，**透明的地方没有纸**——点在图案外面抓不到它，底下的东西照样能刮；右下角的名字签也算贴纸，点它也能揭。
- **小动物**：小鸟停在上沿冒「！」的时候、猫走过的时候、壁虎乱爬的时候，**点它就赶走**。壁虎有几率断尾，尾巴粘在玻璃上扭，刮一下或点一下弹掉。
- **擦窗机器人**：自己找最脏的地方擦，你可以拖着它去别处（拖的时候也在擦）。好几台的时候会各擦各的。
- **保护膜**：顶上写「@B 的保护膜 · 还能挡 N 下」。挨砸会裂，挡满了自己碎开掉下去，膜上的脏东西跟着一起掉。也可以自己提前撕：**拖住右下角的翘角往左拉**，撕开的线扫到哪里，那里的脏东西就跟着膜一起没了，拉过三成松手自动撕完。
- 鼠标在玻璃上一直是一个白圈（中间粉点），不会找不到；指到能点、能拖的东西上，光标会变成手形。

## 露脸区：被淹没、只剩一张脸

- 默认只框住脸（一个 12 个点的椭圆形多边形），框外面可以被糊满。框的形状和位置在设置 →「④ 你的脸」里改（见上面）。
- **淹没感**（高级设置，默认 85%）：越大，小广告越多张直接贴着框的边（只留一条缝），新砸来的脏东西也更爱往脸边上落；一圈纸边和泥点自然围出露脸的空隙。**不裁东西**：小广告按整张纸算，绝不压到框里；泥巴、鸡蛋、奶茶落在框边时，伸向框里的尖刺、飞溅点、流痕直接不画，往下流的蛋黄和茶痕流到框边就停。拉到 0 就离脸远远的。
- **边缘羽化**（高级设置）：框的边多软。
- 框里点不到小广告（看不见的部分不会被误抓）；猫、鸟、壁虎、机器人不会挡在框里。

## 小广告长什么样（17 种，轮着来）

今日擦玻璃、寻猫启事、垃圾分类、擦玻璃同好会、钥匙招领、节约用水、刮玻璃小课堂（横格本）、到此一擦纪念卡（票根）、猫猫今日食谱、擦玻璃健身操、失物招领（牛皮纸，捡到鸡蛋一枚）、玻璃观景台（方格纸）、擦窗小队集合、便利贴「白曜到此一游」、好运贴纸、易碎品快递标签、鸡蛋运输中。

纸有白纸、牛皮纸、横格本、方格纸、便利贴、不干胶（带白边和反光）、标签、票根；粘法有浆糊、胶带、便利贴背胶、不干胶。

**我的贴纸**是你自己上传的图（见上面「设置 → 我的贴纸」），异形、带白边，右下角小白签写送的人。

**@ 后面写的是送这张小广告的观众的昵称**（贴的人 / 发起人 / 导游 / 司机……那一行）：谁送的就写谁，没有预设的名字。试玩面板、自动演示和演示视频里没有真观众，用的是「小明」「鸡蛋侠」这些假名字；点设置里的 ▶ 试，写的是「试用」。

## 观众互动

哪个礼物来什么、来多少，都在设置的两张礼物表里定（见上面「设置」）。**数量不封顶**：每行能填到 9999，送多个礼物再乘上去；一次放不下的拆成好几批排队，一批批来（一批最多：鸡蛋 40 个、泥巴 50 团、奶茶 12 杯、小广告 / 我的贴纸各 40 张；猫一只最多踩 80 个脚印、鸟一只最多拉 12 坨，多了就来好几只）。比如有人一口气送 1314 个一次来 5 下的礼物，会来 6570 下，一批批连着砸好几分钟。嫌东西太大或太小：高级设置 →「东西大小」（0.5～4 倍）。

| 互动 | 表现 | 你怎么应对 | 「一下」是多少 |
|---|---|---|---|
| 扔鸡蛋 | 准星预警 → 碎在玻璃上，蛋黄慢慢往下滑留印 | 点准星接住；没接住就刮两遍 | 2 个 |
| 泼奶茶 | 茶渍 + 往下流的茶痕 + 粘住的珍珠（滑一小段就粘住） | 刮；刮条扫过把珍珠弹下去，也能点珍珠 | 1 杯 |
| 甩泥巴 | 泥团 + 一圈泥点 | 刮两遍 | 3 团 |
| 贴小广告 | 17 种小告示，从一头往另一头抹平贴上，一个角/一条边翘着 | 顺着贴的方向从翘起处往回揭；撕歪了会烂 | 2 张 |
| 我的贴纸 | 你上传的图做成的异形白边贴纸，轮着贴，右下角写送的人；还没上传时照常贴小广告 | 和不干胶小广告一样顺着揭 | 1 张 |
| 哈气写字 | 一团雾，手指在上面写「名字来过」（字是透明的） | 刮掉；不刮停一会儿自己散（散掉不算擦） | 1 团 |
| 猫猫踩过 | 猫从边上走过，一路泥脚印 | 点猫吓跑它（后面不再留脚印） | 1 只 |
| 小鸟拉屎 | 停在上沿冒「？」「！」，到点拉在下面 | 预警时点它赶走 | 1 只 |
| 壁虎 | 肚皮贴玻璃到处爬、挡视线 | 点它赶走（可能断尾） | 1 只 |
| 擦窗机器人（保护） | 背上写名字，自己擦；盯着一块擦干净再换下一块，贴着露脸区和屏幕边也擦得到；没活干会提前下班 | 不用管，也能拖它 | 保护礼物里写几台 |
| 保护膜（保护） | 贴满整块玻璃，「@B 的保护膜 · 还能挡 N 下」，挨砸越多裂纹越多 | 不用管，挡满了自己掉；也能拖右下角提前撕 | 保护礼物里写能挡几下 |

**自己落灰**：玻璃快擦干净、又没人送礼的时候，会自己慢慢落一点灰，让你手上一直有东西擦；礼物一多就不落。高级设置 →「自己落灰」里选：关 / 少 / 正常（默认）/ 多。

弹幕和点赞不触发互动（V1.5 起去掉了）。

## 上限（设置 → 高级设置 →「上限」）

**默认全都不限**，想限哪项就自己填数字（0 = 不限）：

| 项 | 默认 | 填了数字以后 |
|---|---|---|
| 两次捣乱最短间隔 | 0（不留间隔，一帧一条） | 捣乱之间至少隔这么多毫秒（保护类不受限） |
| 排队最多 | 不限 | 排满了新来的跳过（会提示） |
| 同一个观众同时最多 | 不限 | 他的"主块"超了，多的记成名字牌上的「×N」 |
| 玻璃上同时最多 | 不限 | 超了先挤掉最早的灰 |
| 场上同时最多猫 / 小鸟 / 壁虎 / 擦窗机器人 / 小广告 | 不限（各一项；我的贴纸算在小广告里） | 满了的在队里等 |
| 排队最多等 | 0（一直等） | 卡在"场上同时最多"上等太久的跳过（会提示） |

下面这些不是"上限"，是为了直播不卡、不爆内存的做法，**不会少东西**：

- **陈年污垢（沉淀）**：玻璃上**单独的脏东西超过 100 块时，最早的会沉成一层"陈年污垢"**：样子不变、照样能刮，刮干净照样叮、照样计数、照样算到送的人和机器人头上，但内存不再往上涨。刚出现的、正往下流的、贴在保护膜上的、正在刮的不沉。
- 礼物刷得太猛、来不及沉的时候，新的捣乱在队里多等一会儿，一批批来（保护类不等）。
- **小广告叠得很厚时**，整张被上面盖住、一点都露不出来的那几张先不画、不占内存；上面那张一揭开、哪怕露出一角，它就原样画回来，一模一样，揭开时是一点点露出来的，不会闪一下。
- 保护膜同时只有一张，再送是加耐久；膜上积了 150 块以上时，最早的跟着膜"掉"。奶茶珍珠全场 120 颗以上时最早的先掉下去；名字牌只给最新的 8 块显示。
- **画面不变就不画**（V1.5）：玻璃静着的时候（没人送礼、没人刮、东西都停下来了）一帧都不重画，显卡几乎不干活；往下淌的流痕、滑着的珍珠这种慢慢动的，攒够一个像素才画一次；一刮、一砸、一动，马上照常每帧画。
- 旧设置里这几项如果还是以前的默认值（120 块、30 块、10 万、0.7 秒、排队 60），打开新版会自动换成"不限"；自己改过的照旧。

## 抖音合规

插件在抖音直播里用，画面上的东西都按平台规矩来：

- **小广告内容**：17 种都是和这块玻璃有关的好玩小告示。不出现联系方式（电话、微信、联系人之类的字）、价格和钱、招聘和收入承诺、二维码和条形码、真实品牌、礼物和粉丝团、低俗内容；观众名字只写在"谁贴的"那一行。
- 画面上没有"送什么礼物会怎样"的字（礼物表只在设置里，设置面板别开着直播）。
- **观众昵称**上屏前过一道**写死的过滤**：带联系方式或站外引流（微信 / vx / qq / 扣扣 / 私信 / 加群 / 电话 / 扫码 / 链接……）、网址、红包 / 返利 / 刷单 / 兼职 / 赚钱 / 贷款 / 转账、赌、黄的昵称显示成「观众」；**连着 5 个以上的数字**打码（抖音默认昵称「用户1234567890」显示成「用户***」；1314、520 这种不拦）。只影响显示，同一个人还是按抖音 ID 认。
- 昵称只当纯文本显示。
- **我的贴纸**是主播自己上传的图，插件不看图里的内容，合不合规由主播自己把关（别放二维码、联系方式、品牌、低俗图片）。

## 直播接入

- 菘蓝 / 白曜的原始礼物（`SonglanPlugin.onGift`），受设置最上面「接收直播间的礼物」开关控制（默认开）。弹幕、点赞不接。
- 白曜规则动作（`BaiyaoPlugin.onAction`）不受开关限制，也不走礼物表。动作 id 就是互动名：`egg` 扔鸡蛋、`tea` 泼奶茶、`mud` 甩泥巴、`flyer` 贴小广告、`sticker` 我的贴纸、`fog` 哈气写字、`cat` 猫猫踩过、`bird` 小鸟拉屎、`gecko` 壁虎、`robot` 擦窗机器人、`film` 保护膜。`value` 是数量（几个 / 几团 / 几只 / 保护膜能挡几下；不填就用「一下」的量：鸡蛋 2 个、泥巴 3 团、保护膜挡 20 下……），`repeat` 再乘上去。
- 所有互动先排队（默认不限条数），默认一帧放一条、不留间隔；保护类不受间隔限制。
- 设了"同一个观众同时最多"时，他的"主块"（蛋黄、流痕、胶印、浆糊印这些附属痕迹不算）超过上限，多的记成他名字牌上的「×N」。

## 存档

- 设置存 `glass2d.v3.settings`（V1.5 也用这个，V1.6 只是不再读「表里没有的礼物」那一行）。第一次打开会从更早的旧版搬过来，旧的那份不动，退回旧版也不会乱：
  - V1.4（`glass2d.v2.settings`）：礼物表没改过的换成新的两张表；改过的，机器人、保护膜那几行进「保护礼物」（保护膜以前一次 60 秒，按一次挡 20 下换算），其余的进「捣乱礼物」（每个来几下 = 原来的数量）；「表里没有的礼物」那一行新版没有了，原来靠它的礼物需要的话自己加进表里；
  - V1.3 及以前（`glass2d.v1.settings`）：先按 V1.4 的规矩换一遍，再照上面换；
  - 旧的椭圆 / 圆角露脸框换成同样大小、同样位置的多边形（没调过的换成新的默认框）。
- 统计存 `glass2d.v1.stats`（试玩台单独一份）。读不出来只提示，不覆盖。
- **我的贴纸**存在浏览器的 IndexedDB（`glass2d-stickers`）里，不占设置的地方；一张缩到最长边 512 像素以内，几十张也就几 MB。**跟着浏览器走**：OBS 的浏览器来源、白曜、试玩台用的 Chrome / Edge 各是各的，在哪儿用就在哪儿上传一次；清浏览器数据会一起清掉。
- 玻璃上的脏东西不保存，刷新就是干净的；不会重放旧礼物。

- V1.5 礼物：捣乱礼物只从勾上的捣乱里随机，次数在范围里随机、两头都取得到，送几个来几轮；保护礼物来机器人、保护膜（耐久在范围里随机）；两张表里都没有的礼物不管多贵都没反应；两张表重名、范围填反、坏数据都能纠正；V1.4、V1.3 的设置都能搬过来。

- V1.5 性能（和 V1.4 比，同一台机器、同样的东西）：玻璃干净没人动时，V1.4 每帧都重画，V1.5 一帧都不画（主循环每帧 0.15 → 0.04 毫秒）；满屏脏东西、流痕还在往下淌时，每秒重画的次数降到原来的五分之一，砸完约 35 秒后完全停下来不画；一直有人刷礼物时照常每帧画（主循环约 1 毫秒）。露脸区的遮罩改成一张小图，点再多也不影响每帧的开销。
